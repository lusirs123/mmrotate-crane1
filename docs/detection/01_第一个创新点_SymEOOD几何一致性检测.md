## 2. SGAR：共享几何分配与回归的实际组成

**方法命名（2026-10-31）：SGAR（Shared Geometry for Assignment and Regression，共享几何分配与回归）**，指以共同几何度量连接预测感知分配与旋转框回归的完整设计。SGAR是设计名称，R4是采用该设计的当前检测器配置编号，两者不作为同义名称使用。论文以SGAR、Midpoint、LVSR组织三项设计；结果与复现记录保留R4及具体权重身份。

该设计以共同的对称KLD几何依据连接正样本选择与旋转框回归。论文按“共同几何度量—用于预测感知分配—用于回归监督”的顺序说明完整方法，不对两处用途另设字母模块编号。历史实验与源码曾将分配和回归分别编号为A、B，该映射仅供追溯，不用于当前贡献命名；名称统一不改变历史实验身份或证据范围。

### 2.1 共同几何依据与计算

#### 共同对称KLD算子

对框b=(cx,cy,w,h,θ)，μ=(cx,cy)，Σ=R(θ)diag((w/2)²,(h/2)²)R(θ)ᵀ。原始距离为：

```text
d = 0.5 * [tr(Σ_gt^-1 Σ_pred) + tr(Σ_pred^-1 Σ_gt) - 4
           + (μ_pred-μ_gt)^T (Σ_gt^-1+Σ_pred^-1) (μ_pred-μ_gt)]
```

在数值保护未触发时，这是双向KL之和（Jeffreys散度），不是双向平均。等价宽高交换/角度表示可得到相同协方差；正方形协方差不含方向，不能保证正方形旋转框IoU等价。

实现包含宽高下限1、行列式下限、逆矩阵元素限幅及d上限1e4。保护区域不能无条件声称严格尺度不变。对同中心、同尺寸且仅角度不同的框，理论角度项为(ρ²+ρ⁻²−2)sin²(Δθ)，ρ为长短比；不是指数级角度放大或零容忍。

#### SGAR中的预测感知分配

```text
class_cost = 0.25 * (1-p)^2 * [-log(p+eps)]
assignment_cost = class_cost + 2*d/(tau+eps)
```

分配在no_grad下进行，每GT选最小代价候选。前2000近似更新使用9个正样本，随后2000次由9递减至1，之后保持1；不是从第一步起始终一对一，也不是多目标Hungarian全局冲突解算。

温度在1000近似更新内10→1。迭代数由逐图调用计数除以2近似，每卡独立，依赖历史batch设置。温度调整代价尺度，不替代矩阵数值保护，不保证平滑时序输出。

#### SGAR中的回归监督

```text
L_reg = 2 * weighted_reduce(min(sqrt(1+d)-1, 10), positive_normalizer)
```

只对已分配正样本回归；梯度进入框预测及共享特征。d>120时最终截断支路梯度为零，不由此推断训练普遍饱和。sqrt变换与分配原始距离不同，不称优化方向绝对一致。


分配和回归是SGAR中的两个计算用途；当前110与R4均关闭历史分类几何加权、使用普通Focal。R4相对110只在回归路径增加4层卷积塔，没有改变本节几何公式；该结构现已纳入最终检测前端。结构设置与几何计算分别交代，不能将回归塔的作用归因于对称距离本身。

### 17.2 唯一新增组的精确修改范围

| 改动位置 | 设计内容与代码复用入口 |
| --- | --- |
| 主预测器 `train_cfg.pola` | 用已有 [PolaKLDGeometryV1](../../mmrotate/core/bbox/assigners/pola_kld_geometry_v1.py) 替换原 `PolaAssigner`，设置 `geometry_mode='kld'`、`eps=1e-6`；其余原字段保留。原分类代价系数1、几何代价系数1，分配代价为 `class_cost + d_sym` |

共享底层几何量复用 [sym_kld](../../mmrotate/models/losses/sym_kld_calculator.py)。回归值为 `2 * weighted_reduce(min(sqrt(1+d_sym)-1, 10), original_positive_normalizer)`，沿用现有数值保护，不改成混合DIoU回归，也不搜索新系数。分配使用原始几何量，回归使用压缩变换；“共享”不意味着数值或梯度完全一致。
