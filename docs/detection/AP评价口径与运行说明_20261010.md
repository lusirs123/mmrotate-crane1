## 2. 固定评价口径

旋转IoU阈值分别0.50、0.75，匹配使用逐图最大IoU及降score贪心一对一规则，重复检测为FP。全域输出按score排序计算PR；分母包含全部GT及无输出帧。采用本项目MMRotate默认的**VOC2007十一点积分**，单类AP等于该协议的单类mAP，但主表标为AP50／AP75。保留原图顺序和NumPy默认argsort的并列score处理，报告软件版本。

CPU路径复用`eval_crane_offline.compute_riou`，按`mmrotate/core/evaluation/eval_map.py`匹配和十一点积分规则实现参考计算。默认`--backend mmrotate`另外调用项目原生`eval_rbbox_map`：两IoU阈值分别调用、`use_07_metric=True`、`nproc=1`，逐PR点核对（绝对差≤1e−7）、AP核对（绝对差≤2e−6），通过后报告原生AP。缺依赖、缺字段、SHA不符或核对不一致直接失败，不经过会吞掉mAP异常的CraneDataset包装。

原标注与保存GT同时以SHA绑定。当前OpenCV4.12重新执行minAreaRect与服务器保存GT可出现近等面积边方向选择差异；最大中心分量差0.06366px、角差0.001281rad，二者最小RIoU0.99584。因此不要求跨版本转换逐字相等：另核对保存框包围原四点（容差0.001px）、面积与重算最小矩形相对差≤1e−5。全部887帧通过，**计算始终使用保存GT，不替换成当前重算GT**。这不是AP阈值调整。
