## 2. 为什么做这一项改进

**事实：** 既有形状加权、尺寸监督以及冻结ROI上的展平FC、中心联合/独立头没有形成稳定的联合probe收益。当前B的覆盖较好，几何残差较小；继续改变损失权重或头容量并未证明能获得目标特定的细修正。

**机制推断：** 将局部空间布局保留到坐标读出，并以明确几何点而非仅中心/边长/角度参数进行监督，可能帮助利用本人ROI中的定位信息。本方案检验这一问题，但旋转采样、卷积头和点监督共同变化，收益不能单独归于“空间分辨率”“四点监督”或唯一根因。

四点由OBB标注的确定性几何生成，不是新增人工关键点标签，也不保证对应可见的实体边界。遮挡、背景和近方形目标仍可能影响读出。

## 3. 已实现的具体方法

### 3.1 冻结前端和旋转局部采样

冻结B骨干、FPN和检测头。沿原B的规范化旋转轴，在首层P3（stride8、256通道）上做局部双线性采样，得到9×9 ROI及1通道有效区域support。上下文边长为B对应边长的1.5倍，各边至少16个模型输入像素。

采样复用现有坐标与padding合同，使用grid_sample、align_corners=False；这不是新增可学习RoI Transformer。原等比例输入变换不改，整数resize造成的实际sx/sy差异分别处理。原框的raw宽高—角度关联先核验，再仅在内部几何计算中规范化。

基本流程为：

> 图像 → 冻结B及P3 → 以B框定义旋转ROI → 四个空间分布 → 校准后的四点 → 原图矩形解码 → 固定整框回退 → 输出框；输出数量和分数沿用B。

### 3.2 空间卷积头

输入为256通道ROI、1通道support及2个固定局部xy坐标通道，总计259通道。结构为：

    Conv1×1(259→32) + ReLU
    Conv3×3(32→32, padding=1) + ReLU
    Conv1×1(32→4, bias=False)

新增17,696个参数。保留9×9空间布局，不展平为FC；没有BN、dropout、上采样或额外教师。四个输出通道各对应一个几何点的空间logit，末层权重全零。

参数量小是已知结构事实；尚未测得公平的正式部署FPS增量，不能据此宣称已证明实时性或零开销。

### 3.3 B先验与连续残差读出

设原B四中点为 \(p_j^B\)，其归一化ROI位置为 \(a_j\)，81个网格位置为 \(g_k\)。每个点使用固定B-only高斯log先验：

\[
Q_{j,k}=-\frac{\|g_k-a_j\|^2}{2\sigma^2},
\qquad \sigma=\frac{1}{9-1}=0.125.
\]

这里的sigma为一个ROI网格间距，不是一个原图像素。网络输出为 \(L_{j,k}\)，归一化分布与先验分布分别为：

\[
P_{j,k}=\operatorname{softmax}_k(Q_{j,k}+L_{j,k}),
\qquad P^0_{j,k}=\operatorname{softmax}_k(Q_{j,k}).
\]

连续点读出为：

\[
\hat z_j=a_j+
\sum_kP_{j,k}g_k-\sum_kP^0_{j,k}g_k.
\]

减去先验本身的期望，使零logit修正保持B点。它处理指定离散/截断先验的初始化偏移；**不是已证明能消除所有softmax/积分回归偏差的通用方法**。概率图是点位置读出的中间表示，不是检测置信度、分量可靠性概率或可见边界认证。

末层全零时，代码显式返回原B框，确保全部六个输出值逐位一致，而不是依靠三角运算近似相等。连续读出允许网格间坐标，9×9插值没有增加P3的原生空间分辨率。

### 3.4 监督与等价点匹配

原GT OBB生成四点，按规范化轴顺序 \((+u,+v,-u,-v)\) 排列。比较四种循环排列，选择与冻结B参照点的归一化平方距离最小的一种；同分使用第一个argmin。预测点不参与目标匹配。

仅用等权ROI坐标SmoothL1监督：

\[
\mathcal L_{\mathrm{point}}
=\frac1{8N}\sum_{n=1}^N\sum_{j=0}^3
\sum_{d\in\{x,y\}}
\operatorname{SmoothL1}_{\beta=0.1}
(\hat z_{n,j,d}-z^*_{n,j,d}).
\]

没有新增中心、尺寸、角度、IoU或分类辅助损失，没有GT热图匹配损失。π周期、宽高交换通过点集及循环匹配处理；近方形目标不人为增设实体长轴标签。点代理损失与原图px/RIoU不是相同目标，须分别评价。

GT、匹配和损失只存在于离线函数；在线forward和接受规则不接收GT、域、序列或误差信息。

### 3.5 原图坐标与固定矩形解码

点偏移依据模型B旋转轴及上下文边长映射回原图，x/y分别除以实际sx/sy。现有检测框还原、annotation框缩放及深度接口不改。

从四个原图点计算：

\[
c=\tfrac14\sum_{j=0}^3p_j,\quad
u=p_0-p_2,\quad v=p_1-p_3,
\]
\[
\theta=\operatorname{atan2}(u_y-v_x,u_x+v_y).
\]

令 \(e=(\cos\theta,\sin\theta)\)、 \(n=(-\sin\theta,\cos\theta)\)，对应边长为 \(u\cdot e\)、 \(v\cdot n\)。解码后按原B的raw宽高关联和最近周期角输出。另记录四点与正交重建点之间的RMS；不宣称这是全局最优矩形拟合。

### 3.6 原固定回退及输出约束

候选非有限、边长不正、方向退化、任一点出ROI，或下列任一界限失败时，整框回退原B：

- 中心移动不超过0.30×B短边；
- raw两边比各在[0.8,1.25]内；
- 周期角修正不超过10°。

这些界限在结果前固定。没有按分量截断、GT挑选、score重排或时序平滑；点损失不通过回退后的框计算。

B无输出时仍无输出；B有输出时保留输出数量及分数。这是结构上可核验的输出身份保持。**全帧中心正确覆盖、细几何或深度精度不具有同样的结构保证**，本次保持来自实际测量。

### 6.2 当前可以讨论的具体设计差异

**已实现的差异：**

## 7. DFR和ACI恢复：目标与待验证路线

**事实：** v1按单帧独立读出，没有时序监督/在线滤波。sim的DFR与ACI已改善，需要重点补救的是real；当前数据尚未确定real退化的唯一原因。

用户认可保留该候选，希望后续微调恢复real时序。本轮只记录这个目标，没有确定新公式、系数、窗口或预算，也没有修改代码。旧C2有限信息对照仍为未实施建议；本轮没有自动启动C2或时序路线。

**建议先核对的有限问题：** 使用已有TRAIN/VAL连续片段，检查修正后的对角线/周期角相邻变化，是更接近真实GT变化，还是加入了不必要的修正波动。DFR测量预测框对角线帧间相对变化，ACI测量预测角度连续性；单纯把值压低/抬高可能同时压掉真实尺寸或方向变化，不能据指标单独保证运动测量正确。

**可讨论但尚未定版的设计方向：** 若证据表明确有修正噪声，可考虑仅针对几何修正残差的时序一致性，或加入简单因果残差平滑作对照。需要有相邻且连续的TRAIN帧，不使用稀疏64图当完整时序数据；以GT−B的真实残差变化为监督参照，区分真实运动和噪声。此处不是已选择的算法，系数/角度等价处理/延迟/断帧规则仍待固定。

无论采用哪一方向，必须同时守住：

- TRAIN用于学习，固定VAL用于选择；已多次暴露TEST只做最终冻结方案的探索性报告，不能用于系数/窗口/seed/权重或架构挑选。
- 只用当前及过去帧，处理π周期、宽高交换和原图坐标；跨序列、断帧、无输出须明确定义，不补出原B缺失的检测框。
- B身份、等比例变换、score及深度接口保持；检查real覆盖、RIoU、sim角度及真实变化跟随误差，避免用迟滞换取表面稳定。
- 新设计单独标版本与预先评价条件，原v1公式、结果、门槛和失败记录保持。该目标不撤销原probe条件，也不把新时序设计当当前已实现内容。
