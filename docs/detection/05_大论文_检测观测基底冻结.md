#### 0.5.3 建议实施顺序与验收

1. **先定位：** 在单独诊断入口中，给检测输出转换、P3局部采样、M网络/先验/重建、L输入核验/重采样/网络/双次解码/交付加范围标记，记录CPU wall time、CUDA事件/trace、复制与标量同步；正式速度仍用无profiler的既定完整路径复测，避免把分析工具开销或逐段强制同步当成正式速度。
2. **先做等价流程优化：** 优先同帧几何复用、检查去重、常量网格缓存、未使用Q特征采样和诊断量消除、检测框GPU直通。保持三权重、结构输出定义、精度、阈值、支持掩膜和回退规则；严格审计路径保留。新版本单独登记，旧冻结入口及结果留存。
3. **再决定是否压缩模型：** 若R4/预处理仍主导，可据profile研究网络压缩、混合精度或执行后端；这些可能改变数值或权重，属于独立实验，不与纯等价实现提速混称。当前GTX 1080/FP32结果不能保证其他设备或精度模式收益。
4. **先VAL定方案：** 逐帧核对存在性、得分、OBB、中心/方向、尺寸、接受/回退决定和非有限输入处理；覆盖无目标输出、边界、正方形、轴序变化、零残差和支持不足等情况。纯等价版本首先要求严格决定一致和既定数值容差，若放宽容差应在VAL预先说明；变化超界则按方法改动另评，不在已暴露TEST上调阈值追分。
5. **最后固定评价：** 在相同硬件/输入/精度/预热/重复与计时窗口下，完整报告优化前后平均/P95、FPS、allocated/reserved/驱动采样显存及参数量，再以固定版本报告精度。若用于大论文距离观测，还须在原标定不重拟合的条件下核对深度有效性、MAE/P95和变化误差；不能仅凭2D框误差小断言测距不受影响。
