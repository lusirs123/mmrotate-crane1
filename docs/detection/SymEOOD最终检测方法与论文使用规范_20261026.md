# SymEOOD最终检测方法与论文使用规范

日期：2026-10-26。状态：用户已确定后续检测底座；方法组成和权重身份冻结。本文是后续论文使用入口，不是整篇论文定稿或下游迁移完成报告。

## 1. 最终定位

SymEOOD面向港口抓斗有向检测，在预测感知样本分配与旋转框回归中采用共同的对称KLD几何依据，以普通Focal完成分类。重点验证正确覆盖、定位质量与连续观测表现，不将已有高斯表示或KLD技术宣称为首次提出。

论文将分配与回归视为一个相互关联的任务适配设计，不拆成两个强理论创新。整体研究围绕抓斗检测与图像尺寸精度展开：检测器提供初始框，midpoint承担局部整框细化，LVSR承担尺寸专用修正。后两项在新底座上的有效性仍需核查与验证，不能提前宣称整条链已完成。

本文描述最终采用的方法；论文正文不叙述分类模块探索、删除或替换过程，不介绍其机制诊断实验。历史研究记录完整保留，避免将最终方法与早期不同模型结果混用。

### 7.3 共同口径与可用结论

- 中心正确为误差＜15px／全部GT帧；mean_RIoU对缺输出记0。Sim门控角RMSE在中心误差不满足＜10px或缺输出时记90°，不能当作纯角度误差。
- DFR为相邻有效输出框的对角线相对变化，单位%/帧；ACI按原35°变化尺度计算。两者不是几何正确性的替代，也不扣除真实运动。
- MCML为RIoU＜0.5（包括缺输出）的连续失败；mean为连续片段最大失败长度的均值。TDR为10帧窗口至少命中一帧的比例。MRF无可定义恢复事件时显示“—”，不是0。
- 本消融CSV没有独立定位命中列，不由中心正确数替代或推算；其余完整指标保留原分析入口。
- 同批次TEST中，A+B的中心覆盖、DFR及最长失败优于两个单因素，但mean_RIoU不及仅A，ACI与Sim角度不及仅B。因此支持任务目标下的取舍，不能写成各指标全面协同。
- 000严重学习失败，ACI等平滑指标仍可能较高，说明“平滑”不能代替“正确”。它不是原EOOD，不将它用于夸大相对原模型增益。
