# SymEOOD新旧完整链路：TEST与深度估计性能总表

整理日期：2026-10-27。用途：后续阶段消融、误差分析与论文结果查阅。仅汇总既有封存结果，未训练、推理、重算原始交集、重选版本或重拟合标定。

## 1. 范围、版本与口径

包含旧B24→旧midpoint M3→旧A20→旧C6，以及新110 ep20→新midpoint M21→新共同阶段ep7→新C3／固定C6，共九个版本。C3和C6为从同一ep7延续过程中不同轮次的检查点，不是两个独立训练重复，也不是串行叠加两个尺寸头。

旧A20、旧C6、新ep7、新C3均是原排序下的描述性代表，原合格选版均为空；新C6是预先保留的固定末轮辅助，不能因TEST／测距更好替代C3。历史正式M身份不变。

TEST共1440帧，Real868（seq03=200、seq04=668），Sim572（seq09）。九版输出均1431，但不能据总数相同假定逐帧输出集合相同；有效邻接数单列。测距为另一组Unknown-02，共1097帧，九版均全部输出且数值有效，共同有效帧也是1097；缺失与数值失败均0。两组数据均已暴露，仅作冻结工程比较，不作为独立泛化证明。

尺寸MAE／P95／bias按各自有输出帧统计；中心MAE也为输出条件值。联合尺寸正确要求长短边绝对相对误差同时≤10%，同时保留全帧与输出条件比例。中心正确和定位命中不同；RIoU按全帧统计。长短边分别规范排序，bias=mean(pred/GT−1)×100%，负值为偏小。

尺度a=(ln(l/l*)+ln(s/s*))/2，比例r=ln(l/l*)−ln(s/s*)；abs-a／abs-r无量纲，不乘100。表内率统一注明百分数，原CSV中的fraction字段保持0—1。DFR单位%/frame；ACI无量纲；MCML以帧计，TDR为10帧窗口命中。AP沿封存脚本口径作为补充，不混称COCO AP；Real及跨域角度原始数值仅保留，不作为可靠方向精度证据。主方向结论限Sim。

所有预测使用原生未取整框，不能混用TXT取整指标。表内展示至六位小数；附录保留原CSV全部字段与原精度，空值代表未提供／不适用，不等于0。
