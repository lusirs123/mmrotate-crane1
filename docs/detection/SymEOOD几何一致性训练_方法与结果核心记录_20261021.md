## 1. 固定定位与三个研究点的关系

**第一项改进的可用定位：** 面向港口抓斗有向检测，在预测感知标签分配、框回归和分类损失加权中使用共同的对称KLD几何依据，并结合渐进正样本分配形成SymEOOD整体训练方案。

这里的“几何一致性”指共同几何距离来源，不是三个目标数值相同、梯度方向相同或性能必然协调。现有实验支持整体模型的Real正确覆盖与连续失败改善；不证明三种机制分别有效或协同必不可少，不主张首创高斯框表示、KLD损失或高斯标签分配。

## 2. 研究问题与实际数据流

研究动机是将旋转框联合几何信息用于监督分配与分类加权，而不只用于末端回归。它是可检验的设计假设，不以“RIoU天然对角度迟钝”或“必然产生单峰”作为已证明前提。

训练：图像 → ResNet50/FPN → 主头分类与旋转框预测 → SymPOLA生成正负标签 → SymNFL分类与SymKLD回归；ATSS辅助头提供额外训练监督。共同更新可训练参数。当前历史SymEOOD主头直接将FPN输入送入预测卷积；不能由配置stacked_convs=4推断实际执行了四层主头塔。

推理：图像 → 主干/FPN → 主头 → score门槛0.05及Top-1输出；本历史配置不运行训练辅助头，不执行旋转NMS。显式max_per_img=1限制输出数量，因此“一个输出”不是网络候选天然单峰的证据。训练损失不进入推理计算，但整套架构成本仍须依据实测，不能称所有改动零成本。

## 3. 三条几何通路的准确实现

### 3.1 共同对称KLD算子

对框b=(cx,cy,w,h,θ)，μ=(cx,cy)，Σ=R(θ)diag((w/2)²,(h/2)²)R(θ)ᵀ。原始距离为：

```text
d = 0.5 * [tr(Σ_gt^-1 Σ_pred) + tr(Σ_pred^-1 Σ_gt) - 4
           + (μ_pred-μ_gt)^T (Σ_gt^-1+Σ_pred^-1) (μ_pred-μ_gt)]
```

在数值保护未触发时，这是双向KL之和（Jeffreys散度），不是双向平均。等价宽高交换/角度表示可得到相同协方差；正方形协方差不含方向，不能保证正方形旋转框IoU等价。

实现包含宽高下限1、行列式下限、逆矩阵元素限幅及d上限1e4。保护区域不能无条件声称严格尺度不变。对同中心、同尺寸且仅角度不同的框，理论角度项为(ρ²+ρ⁻²−2)sin²(Δθ)，ρ为长短比；不是指数级角度放大或零容忍。

### 3.2 SymPOLA：预测感知分配

```text
class_cost = 0.25 * (1-p)^2 * [-log(p+eps)]
assignment_cost = class_cost + 2*d/(tau+eps)
```

分配在no_grad下进行，每GT选最小代价候选。前2000近似更新使用9个正样本，随后2000次由9递减至1，之后保持1；不是从第一步起始终一对一，也不是多目标Hungarian全局冲突解算。

温度在1000近似更新内10→1。迭代数由逐图调用计数除以2近似，每卡独立，依赖历史batch设置。温度调整代价尺度，不替代矩阵数值保护，不保证平滑时序输出。

### 3.3 SymKLD：回归监督

```text
L_reg = 2 * weighted_reduce(min(sqrt(1+d)-1, 10), positive_normalizer)
```

只对已分配正样本回归；梯度进入框预测及共享特征。d>120时最终截断支路梯度为零，不由此推断训练普遍饱和。sqrt变换与分配原始距离不同，不称优化方向绝对一致。

### 3.4 SymNFL：几何感知分类加权

```text
mu = 1                                      # 普通候选
mu = 1 + exp(-stop_gradient(min_j d_ij)/tau)  # 空间筛选候选
L_cls = 0.25 * weighted_reduce(mu * FocalLoss, positive_normalizer)
```

Focal alpha0.25、gamma2，硬标签；未启用quality target。默认按中心距离选Top-300，KLD分块256，温度10→1/1000近似更新。正常情况下mu在1与2之间，几何越接近权重越大；正负样本都会受标签对应的加权，不是几何误差越大惩罚越接近2。

几何权重detach，不通过该权重直接优化bbox。历史实现按每FPN层展开当前GPU batch、使用该层正样本对应GT集合，并非严格逐图隔离。没有相应GT时回到普通Focal。调用计数除以5近似更新步数，与分配器不是共享的同一个全局步数状态，不写“绝对同步”。

源码入口为[历史源码与训练文件索引](SymEOOD历史训练文件索引_20261021.json)。历史SymEOOD无增强对应c16813c、尺度B对应af8307c；审查时源码不能替代历史版本。

## 4. 基线身份与公平比较边界

EOOD为本项目K=1实现：主头加一个ATSS辅助头，不等于原论文全部多头配置。本次服务器审查已通过历史日志与对应Git源码确认：EOOD主头虽然计算L1，但最终训练loss字典只返回分类与IoU；日志中的loss_1_loss_bbox属于辅助头。不能再照配置写成主头L1＋IoU，也不能据此指认原作者方法错误或断言性能差距由此造成。


| 项目         | EOOD K1                                    | SymEOOD K1                        |
| -------------- | -------------------------------------------- | ----------------------------------- |
| 主头分类     | Focal，weight2                             | SymNFL，weight0.25                |
| 主头有效回归 | RotatedIoU，weight2；未返回独立L1          | SymKLD，weight2                   |
| 辅助分类     | Focal，weight1                             | Focal，weight0.01                 |
| 辅助回归     | L1，weight1                                | SmoothL1 beta1，weight0.01        |
| 主头特征通路 | EoodHead包装与分类/回归通路                | 历史forward_single直接预测FPN输入 |
| 输出处理     | 原多候选/旋转NMS路线，任务评价读取最高分框 | 无NMS，显式Top-1                  |

因此EOOD→SymEOOD是整体实现比较，包含结构、监督强度和后处理差异。四格实验可以分开整体模型与尺度增强作用，不能分离三个训练机制或证明“共同度量协同”是唯一根因。

### 6.3 结果应如何解释

- 无增强EOOD→SymEOOD：Real中心覆盖84.68→92.05%，RIoU0.7296→0.7636，MCML101→29帧；Real DFR及Sim几何有代价。
- 同尺度EOOD→SymEOOD：Real中心覆盖96.43→98.85%，MCML8→4帧，但Real RIoU0.8230→0.8169，Sim RIoU0.9210→0.8816。支持覆盖/最长失败优势，不支持全域精定位领先。
- SymEOOD无增强→B：Real覆盖92.05→98.85%，MCML29→4；Sim RIoU0.8564→0.8816，但DFR/ACI退化。EOOD同样受益于尺度增强，不能把增强收益归于独有机制。
- DFR是框对角线变化，不是扣除真实运动后的噪声；MCML以RIoU命中定义，不等于纯漏输出长度。不能由连续性指标推导物理防摇效果。

四组完整输出数量/条件中心准确率、双边达标和方向资格分母尚未在本次审查中统一逐帧重算。B后续证据记录输出1431/1440；不能把B输出数套到其他三组，也不能从四舍五入的覆盖率反算当作精确计数。当前四组统一AP主表未由本轮补算，不填假定值。
