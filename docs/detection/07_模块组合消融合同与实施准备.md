## 1. 比较目的与八格矩阵

回答两类问题：各精修模块是否依赖SymEOOD底座；midpoint和LVSR组合是否优于各自单独使用。不得预设完整链路最优。

- E：固定EOOD＋相同尺度增强，原VAL选择ep24。不是无尺度增强的EOOD，也不是严重学习失败的000。
- S：固定新SymEOOD-110 ep20，是替换检测器，不是在EOOD之后串联一个检测器。
- M：原midpoint σ1.5，17696参数。
- L：当前小论文的双分支LVSR，2480参数。无C续训；不是共享头或另一个分类C模块。

| 改进配置 | 本轮处理 | 小头输入／依赖 |
| --- | --- | --- |
| E | 历史控制，保留 | 原固定EOOD输出 |
| E＋M | **新增入口 `eood_m`** | 新E缓存，从头训练M |
| E＋L | **新增入口 `eood_l`** | 同一E缓存，Q=B，从头训练L |
| E＋M＋L | **新增入口 `eood_ml`** | 共用上面E＋M的VAL选版M，再从头训练L |
| S | 历史控制，保留 | 新110固定ep20 |
| S＋M | 历史控制，保留 | 原固定M ep21 |
| S＋L | **新增入口 `110_l`** | 原封存S缓存，Q=B，从头训练L |
| S＋M＋L | 历史控制，保留 | 原固定双分支ep11，无续训 |

这里是四组新小头任务，不是四次检测器重训。E＋M仅训练一次；独立M行和组合ML行使用同一权重。E缓存仅生成一份，三个E分支共同读取；S＋L复用已经封存、核对身份的同一S特征缓存，不重新提取S全量特征。

**证据边界：** E与S来自不同历史检测训练批次；完整SML的ep11也有事后VAL审查及已暴露TEST历史。因此，即使补齐八格，仍是冻结检测器上的模块补充消融，不能写成同一初始化／输入流下新训练完成的严格八臂全因子实验。历史结果不覆盖，不将新结果改名为旧成绩。
