## 2. 三因素的完整定义

### 2.1 A：分配中的几何代价

**共享部分（两态完全相同）**

```text
p          = sigmoid(pred_logits)
cost_class = 0.25 * (1-p)^2 * (-log(p + 1e-8))          # 取对应 GT 列
tau(it)    = 10 - 9 * min(it, 1000)/1000                 # it = _local_call_count // 2
topk(it)   = 9 (it<2000) → 线性降至 1 (2000≤it<4000) → 1
C          = 1.0 * cost_class + 2.0 * cost_reg
候选集合    = inside_flags（valid_flags），与代价无关
```

| 状态 | `cost_reg` | 范围 | 说明 |
|---|---|---|---|
| **A=1（kld）** | `d_symkl(pred,gt)/(tau+eps)`，`d` 上限 1e4 | `[0,1e4]/tau` | 双向 KL 之和 |
| **A=0（iou）** | `(1 - RIoU + ρ²/c²)/(tau+eps)` | `[0,2]/tau` | `ρ²/c²` 是**中心偏移惩罚**，不是 DIoU 值 |

A=0 逐式复刻 `pola.py` L88-99：`rbbox_overlaps` 取旋转 IoU；`obb2xyxy('le90')` 后按 `PolaAssigner.diou` 计算 `inter_diag/outer_diag` 并 clamp `[0,1]`；再取 `1-(IoU-penalty)`。实现见 `sym_pola.py` 的 `_diou_penalty` / `iou_diou_cost`。

**命名边界**：这叫**"固定分配框架下的几何代价替换"**。不是"恢复原 POLA"——原 POLA 无 τ、无 top-9→1 日程、`AssignResult.max_overlaps` 语义不同；本消融也不检验渐进正样本日程本身的作用。

**限制**：保留相同 τ 只统一显式温标，不保证两种代价的数值分布或实际影响相同。分类项、几何项与最终分配变化须分别记录（§8 S1及§13），**不得据此调 τ 或权重**。

### 2.2 B：回归监督

| 状态 | 公式 | 归一化 |
|---|---|---|
| **B=1** | `2.0 * Σ min(sqrt(1+d)-1, 10) / N_pos` | `avg_factor=num_total_samples` |
| **B=0** | `2.0 * Σ (1 - IoU + ρ²/c²) / N_pos` | 同上 |

B=0 用**历史实际生效**的项：EOOD 日志只有 `loss_0_loss_iou`，无 `loss_0_loss_bbox`；`rotated_eood_head.py` L433 算 L1、L537 返回时丢弃。**不补加 L1**。

**限制**：归一化口径一致（同为 `Σ/num_total_samples`，权重 `(n,)`，同一 `weight_reduce_loss` 位置）不等于损失值与梯度尺度可比：`sqrt` 压缩与线性 `1-IoU` 的尾部行为不同。

### 2.3 C：分类几何加权

| 状态 | 公式 |
|---|---|
| **C=1** | `0.25 * Σ (μ_i·FL_i)/N_pos`，`μ_i = 1 + exp(-min_j d_ij / tau)`（detach），仅该层中心距 top-300 参与 |
| **C=0** | `0.25 * Σ (1·FL_i)/N_pos`，即标准 Focal |

C=0 保留 `alpha=0.25`、`gamma=2.0`、one_hot 硬标签、外层 `0.25`、`avg_factor`、`_local_iter` 自增。不使用 `spatial_topk=0`。

**与 `isolate_images` 的组合语义（本轮新增，已写入代码）**：`use_geometry_weight=False` 优先于 `isolate_images`。即 `C=0 + isolate_images=True` 仍为 `μ≡1`，不会因为走了逐图分支而把几何权重带回来。实现顺序为 `if not use_geometry_weight → pass / elif isolate_images → … / elif gt 非空 → …`。

## 4. 数据流

```text
image → ResNet50/FPN(5,256) → retina_cls(1×1) / retina_reg(1×1)
     → 逐图展平 → SymPOLAAssigner.assign（no_grad，逐图 1 次）
     → PseudoSampler → labels / bbox_weights / bbox_targets / num_total_pos
     → 逐层 loss_single ×5 → loss_cls + loss_bbox
```

A 只改 `assign()` 内的 `cost_reg`；B 只改 `loss_single` 的 `loss_bbox`（正样本）；C 只改 `loss_single` 的 `loss_cls`。对固定预测的一次调用，A决定B/C所用样本集合，B/C不直接改变当次分配。训练更新后，分类与回归经共享特征及后续预测相互影响，不能称整个训练过程中B与C互不影响。

### 16.1 当前判断

**现有证据指向“按冻结设计实现的A0B0C0组合出现学习失败，并与既有解码钳制等实现细节相互作用”；尚未发现新增开关、DIoU符号或配置路由写错的证据。失败不是预先设计的目标，也不能因为工程通过就排除所有潜在缺陷。**

这一判断既不是“原EOOD算法有错”，也不是“000本来就应该崩溃”。000保留SymEOOD的直接FPN预测结构、弱辅助权重、正样本归一化、τ与topk日程，再将三个因素关闭；它没有恢复原EOOD的完整结构、辅助权重、初始分配和后处理。因此它是定义清楚的受控参考组合，不能作为唯一强基线为三个创新背书。

### 16.3 为什么这个设计仍可能失败

1. **代价数值尺度未适配。** A0几何项约在[0,2]/τ，A1 KLD可到1e4/τ；名义系数相同并不保证分类／几何竞争强度相同。早期τ=10进一步减小A0几何项。000固定探针显示高分错误大框可以胜过低分合理框，这是分配—分类的具体失配证据。
2. **分配和回归使用的物理范围不同。** 分配读取未作训练图像尺寸钳制的解码框；回归随后把尺寸钳制到1024像素。000 ep2的异常大框进入饱和区域，直接尺寸delta梯度为0。这是既有安全实现的训练局限，不是本轮额外加入的钳制；中心、角度及共享特征仍可能变化，不能称整个网络没有梯度。
3. **所选目标已改变学习环境。** B0没有独立L1，C0没有历史几何加权，辅助监督也保持SymEOOD的弱权重。即便每个关闭状态符合合同，组合后的优化不保证与原EOOD同样容易。
4. **仍有未分离因素。** 当前是一种子、固定超参数。001避开失败说明分类加权也可改变学习轨迹；现有日志与两个TRAIN探针不能确定数值尺度、正样本轨迹、饱和或随机性中谁是唯一主因。

### 16.4 这是否使消融无效？

四组仍然有效回答“在该共同框架、既定系数与该种子下，关闭全部因素会怎样，单独恢复一项会怎样”。但失败参考组不能单独支撑广泛的算法优越性，更不能用巨大增量证明强新颖性。完整论文应结合原EOOD／同增强控制、正常学成的单项与组合结果、以及全部退化指标。

不把A2结果写成纯度量理论比较；它包含实际数值尺度与学习轨迹的变化。不在已暴露TEST上寻找更有利系数。若之后研究数值匹配或取消饱和等机制，须另立预先定义的对照并保留本轮编号及结果。
