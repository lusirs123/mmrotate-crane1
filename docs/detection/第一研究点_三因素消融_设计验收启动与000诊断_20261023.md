## 2. 三因素的完整定义

### 2.1 A：分配中的几何代价

**共享部分（两态完全相同）**

```text
p          = sigmoid(pred_logits)
cost_class = 0.25 * (1-p)^2 * (-log(p + 1e-8))          # 取对应 GT 列
tau(it)    = 10 - 9 * min(it, 1000)/1000                 # it = _local_call_count // 2
topk(it)   = 9 (it<2000) → 线性降至 1 (2000≤it<4000) → 1
C          = 1.0 * cost_class + 2.0 * cost_reg
候选集合    = inside_flags（valid_flags），与代价无关
```

| 状态 | `cost_reg` | 范围 | 说明 |
|---|---|---|---|
| **A=1（kld）** | `d_symkl(pred,gt)/(tau+eps)`，`d` 上限 1e4 | `[0,1e4]/tau` | 双向 KL 之和 |
| **A=0（iou）** | `(1 - RIoU + ρ²/c²)/(tau+eps)` | `[0,2]/tau` | `ρ²/c²` 是**中心偏移惩罚**，不是 DIoU 值 |

A=0 逐式复刻 `pola.py` L88-99：`rbbox_overlaps` 取旋转 IoU；`obb2xyxy('le90')` 后按 `PolaAssigner.diou` 计算 `inter_diag/outer_diag` 并 clamp `[0,1]`；再取 `1-(IoU-penalty)`。实现见 `sym_pola.py` 的 `_diou_penalty` / `iou_diou_cost`。

**命名边界**：这叫**"固定分配框架下的几何代价替换"**。不是"恢复原 POLA"——原 POLA 无 τ、无 top-9→1 日程、`AssignResult.max_overlaps` 语义不同；本消融也不检验渐进正样本日程本身的作用。

**限制**：保留相同 τ 只统一显式温标，不保证两种代价的数值分布或实际影响相同。分类项、几何项与最终分配变化须分别记录（§8 S1及§13），**不得据此调 τ 或权重**。

### 2.2 B：回归监督

| 状态 | 公式 | 归一化 |
|---|---|---|
| **B=1** | `2.0 * Σ min(sqrt(1+d)-1, 10) / N_pos` | `avg_factor=num_total_samples` |
| **B=0** | `2.0 * Σ (1 - IoU + ρ²/c²) / N_pos` | 同上 |

B=0 用**历史实际生效**的项：EOOD 日志只有 `loss_0_loss_iou`，无 `loss_0_loss_bbox`；`rotated_eood_head.py` L433 算 L1、L537 返回时丢弃。**不补加 L1**。

**限制**：归一化口径一致（同为 `Σ/num_total_samples`，权重 `(n,)`，同一 `weight_reduce_loss` 位置）不等于损失值与梯度尺度可比：`sqrt` 压缩与线性 `1-IoU` 的尾部行为不同。

### 2.3 C：分类几何加权

| 状态 | 公式 |
|---|---|
| **C=1** | `0.25 * Σ (μ_i·FL_i)/N_pos`，`μ_i = 1 + exp(-min_j d_ij / tau)`（detach），仅该层中心距 top-300 参与 |
| **C=0** | `0.25 * Σ (1·FL_i)/N_pos`，即标准 Focal |

C=0 保留 `alpha=0.25`、`gamma=2.0`、one_hot 硬标签、外层 `0.25`、`avg_factor`、`_local_iter` 自增。不使用 `spatial_topk=0`。

**与 `isolate_images` 的组合语义（本轮新增，已写入代码）**：`use_geometry_weight=False` 优先于 `isolate_images`。即 `C=0 + isolate_images=True` 仍为 `μ≡1`，不会因为走了逐图分支而把几何权重带回来。实现顺序为 `if not use_geometry_weight → pass / elif isolate_images → … / elif gt 非空 → …`。

## 4. 数据流

```text
image → ResNet50/FPN(5,256) → retina_cls(1×1) / retina_reg(1×1)
     → 逐图展平 → SymPOLAAssigner.assign（no_grad，逐图 1 次）
     → PseudoSampler → labels / bbox_weights / bbox_targets / num_total_pos
     → 逐层 loss_single ×5 → loss_cls + loss_bbox
```

A 只改 `assign()` 内的 `cost_reg`；B 只改 `loss_single` 的 `loss_bbox`（正样本）；C 只改 `loss_single` 的 `loss_cls`。对固定预测的一次调用，A决定B/C所用样本集合，B/C不直接改变当次分配。训练更新后，分类与回归经共享特征及后续预测相互影响，不能称整个训练过程中B与C互不影响。

## 16. 000究竟是设计问题还是代码错误？

### 16.1 当前判断

**现有证据指向“按冻结设计实现的A0B0C0组合出现学习失败，并与既有解码钳制等实现细节相互作用”；尚未发现新增开关、DIoU符号或配置路由写错的证据。失败不是预先设计的目标，也不能因为工程通过就排除所有潜在缺陷。**

这一判断既不是“原EOOD算法有错”，也不是“000本来就应该崩溃”。000保留SymEOOD的直接FPN预测结构、弱辅助权重、正样本归一化、τ与topk日程，再将三个因素关闭；它没有恢复原EOOD的完整结构、辅助权重、初始分配和后处理。因此它是定义清楚的受控参考组合，不能作为唯一强基线为三个创新背书。

### 16.2 实现审查所确认的内容

| 检查 | 结果及意义 |
|---|---|
| A路由 | 使用`model.train_cfg.assigner.cost_reg_mode`，000为iou、100为kld、010/001为iou；没有早期bbox_head.train_cfg误配 |
| B路由 | 000/100/001实际为linear、diou=True、weight2的RotatedIoULoss；010为SymKLDLoss；没有补入历史未返回的L1 |

这份审查没有穷尽所有输入和实现分支；“未发现新增实现错误”不能改写为“全部代码已形式证明无错”。

### 16.3 为什么这个设计仍可能失败

1. **代价数值尺度未适配。** A0几何项约在[0,2]/τ，A1 KLD可到1e4/τ；名义系数相同并不保证分类／几何竞争强度相同。早期τ=10进一步减小A0几何项。000固定探针显示高分错误大框可以胜过低分合理框，这是分配—分类的具体失配证据。
2. **分配和回归使用的物理范围不同。** 分配读取未作训练图像尺寸钳制的解码框；回归随后把尺寸钳制到1024像素。000 ep2的异常大框进入饱和区域，直接尺寸delta梯度为0。这是既有安全实现的训练局限，不是本轮额外加入的钳制；中心、角度及共享特征仍可能变化，不能称整个网络没有梯度。
3. **所选目标已改变学习环境。** B0没有独立L1，C0没有历史几何加权，辅助监督也保持SymEOOD的弱权重。即便每个关闭状态符合合同，组合后的优化不保证与原EOOD同样容易。
4. **仍有未分离因素。** 当前是一种子、固定超参数。001避开失败说明分类加权也可改变学习轨迹；现有日志与两个TRAIN探针不能确定数值尺度、正样本轨迹、饱和或随机性中谁是唯一主因。

### 16.4 这是否使消融无效？

四组仍然有效回答“在该共同框架、既定系数与该种子下，关闭全部因素会怎样，单独恢复一项会怎样”。但失败参考组不能单独支撑广泛的算法优越性，更不能用巨大增量证明强新颖性。完整论文应结合原EOOD／同增强控制、正常学成的单项与组合结果、以及全部退化指标。

不把A2结果写成纯度量理论比较；它包含实际数值尺度与学习轨迹的变化。不在已暴露TEST上寻找更有利系数。若之后研究数值匹配或取消饱和等机制，须另立预先定义的对照并保留本轮编号及结果。

### 20.11 对000、完整组合及论文主张的更新判断

**000：** 全八组证据没有推翻§16的实现审查结论。000符合冻结开关和公式，在共同结构、τ/topk日程及既有钳制下发生严重学习失败。其余七组均学成，但001仍为A=B=0，证明没有KLD分配／回归也可避开失败。不能将失败预先当作设计目标，也不将它重新包装成原EOOD。已有两幅TRAIN探针仅说明一条失败路径，不证明全部样本唯一根因。

**101：** 作为本轮固定配置，提供了更好TEST定位和尺寸达标的组合线索。它不能由于TEST最好就被追认为新正式基线或替换历史B/M，也不能从一个种子宣称普遍最优。A2中量级变化、不同选中epoch以及整体实现边界继续保留。

**历史SymEOOD与创新性：** 本轮111不是历史B的同一权重或逐位重复，不能把其新结果覆盖历史结果，也不能由本轮整体表一举否定已有Real覆盖收益。可以保留任务相关训练组合与实证贡献，必须收窄“三通路协同”的因果主张。完善应先核对归因与正常学成的控制、历史整模型复现及必要重复证据；不为了增强新颖性立即叠加模块或在已暴露TEST上调系数。

### 22.2 目标与实际实现之间的联系

拟检验的目标是“让最终高分输出更可靠，改善正确覆盖和连续观测”；这是研究目标，不能直接作为已实现能力。实际实现及其边界如下：

| 审查项 | 代码事实 | 对目标的意义 |
|---|---|---|
| 分类目标 | `use_quality_target=False`；Focal使用one-hot硬标签，alpha=0.25、gamma=2、外权重0.25 | 没有直接监督分数等于定位质量；不能当作QFL或质量校准头 |
| 加权对象 | 每个FPN层将本GPU批次框展平，按预测中心到传入GT集合的最短距离取top-300；集合不先按正负标签过滤 | 正、负样本都可能被加权，实际数量须逐样本记录，现有结果未保存 |
| GT集合 | `pos_gt_bboxes=decoded_gt_bboxes[pos_inds]`，为该层正样本对应的目标框；并非单独传入完整逐图GT列表 | 几何参照依赖实际分配；该层无正样本GT时跳过几何块 |
| 跨图范围 | `isolate_images=False`；本GPU同层批次的预测与正样本GT合池取最短距离和最小KLD | 没有保证每个预测只参照自身图像GT；存在跨图匹配的实现可能性，尚未量化实际发生率及代价 |
| 权重与梯度 | 选中候选μ=1+exp(−stopgrad(min KLD)/τ)，其余μ=1；KLD先clamp到[0,1e4] | μ在[1,2]，是增强选中样本硬标签损失；经μ到框分支的直接梯度为0 |
| 间接路径 | 分类与回归读取共同FPN；A分配代价也读取分类logits | C仍可经共享特征、分类分数及后续分配轨迹改变框学习；A开关固定不等于正样本集合固定 |

源码入口：[SymNFL几何权重与detach](../../mmrotate/models/losses/sym_nfl_loss.py:183)、[硬标签Focal与乘权](../../mmrotate/models/losses/sym_nfl_loss.py:237)、[共享FPN读出](../../mmrotate/models/dense_heads/sym_eood_head.py:222)、[展平与正样本GT传入](../../mmrotate/models/dense_heads/sym_eood_head.py:672)、[A读取分类代价](../../mmrotate/core/bbox/assigners/sym_pola.py:111)。部分注释写“有梯度微雕”，但最终μ在219行detach，应以实际计算图为准。

对同一固定前向、同一标签、非负样本权重和同一分母，C=1的加权Focal总值介于原值的1—2倍，逐logit梯度也按μ缩放。这同时改变样本相对作用和总体监督强度；共享参数梯度可能存在抵消，不能推导其范数必然按相同比例增大。训练后的不同模型、不同分配更不能由此直接比较梯度大小。

### 23.7 结果解释与下一步

**一、C确实同时增强正、负样本，不是正样本专用的质量目标。** 四组的256个正样本均进入几何Top-K，分别有255／254／255／256个μ≥1.9；负样本进入数为38144／38144／53744／57044，承担分类损失增量的39.517%／44.860%／42.121%／40.245%。本批有效标签没有忽略样本。不能把负样本数量大直接称为错误加权；在一对一分配下，接近GT而未被分配的框仍可能是负样本。空分支是“该层没有传入正样本GT参照”，不是整图没有GT。C仍在放大硬标签Focal，而不是直接训练“分数=定位质量”。

**二、跨图现象真实存在，但本次没有支持它是主要分类损失来源。** 有效Top-K中外图严格更近分别14560／12851／7825／6789个；SymKLD组另有12410／14142个本图参照缺位。可是保持Top-K成员不变、只限制到本图参照后，消去的原加权损失增量仅为0.000070%／0.000037%／0.052644%／0.006590%。大量候选的μ或参照改变，却只携带很小的Focal损失。因此不能根据跨图计数认定它解释了C的效果，也不应把逐图隔离直接当成下一次修复。这个结论限于成熟权重与固定诊断batch；未排除早期训练、Top-K成员竞争或跨batch历史影响，也没有验证逐图重新分配配额的训练效果。

**三、当前RIoU≥0.5失败的直接环节是过滤／最终选择，C没有稳定改善这一环节。** 所有13780个模型×帧的原始候选均存在合格框。四组VAL成功数分别877／873／887／873；100有3帧过滤丢失、7帧排序丢失，101有14帧排序丢失；110没有这类失败，111有1帧过滤丢失和13帧排序丢失。110→111的14个失败全部集中于Real seq07，中心正确也887→872；并非仅由缺输出造成。TRAIN四组均至少2557/2558成功，不能把它们几乎饱和的TRAIN命中率当作VAL可靠性的证据。这里的“排序丢失”只表示该固定模型内有幸存合格候选却没有选中；不同模型的框与分数都变了，不能把110／111之间的全部差异归因于分类排序。更不能用低门槛候选上界证明精定位、尺寸或测距所需证据已经充分。

**四、强度是必须控制的因素，但G并非处处等于统一乘常数。** α均值100／101为1.97050／1.97277，110／111为1.93767／1.81853。匹配总分类损失后，IoU组logits余弦均值0.999848／0.999922，表明成熟状态下大部分即时梯度方向与均匀增强很接近；不能将C开关的全部效应独立归于几何信息。SymKLD的111仍有差异：分类头与FPN参数G/S余弦均值0.985800／0.986476，后者最小0.833749，且G相对S的正样本logits梯度平方范数占比从38.565%升至42.471%。平均相近也会掩盖个别batch差异，例如100的FPN参数最小余弦0.566469。这些差异说明样本间作用没有完全被标量强度解释，但不证明它改善排序或检测。总梯度的其他损失固定，U→G的裁剪触发100为18→20、101为14→17，110／111均为0；不能仅看总范数增量推断分类分支影响很小。

**五、本次补齐的是机制读数，不是C的有效性证明。** 三个问题均有直接记录：μ作用对象／参照、失败阶段、强度匹配后的梯度。仍未分离共享特征引起的框变化与分类排序的训练因果，也未分离Top-K选择、正负再平衡与连续KLD权重各自的作用。成熟固定权重、单种子和单卡诊断，不能替代训练全过程或多种子配对证据。结合§22的同轮VAL反例，现在仍不支持写“C稳定改善高分预测可靠性”或“三因素协同已经成立”。不直接删除C，也不因梯度确有差异就宣布其创新主张成立。

**六、下一步收束到强度匹配的公平控制设计，暂不自动启动训练。** 如果继续检验C，优先冻结U／S／G三态的训练对照：U普通Focal；G原始几何加权；S按同一batch的原G/U计算stopgrad标量、均匀作用于所有有效分类项，保留原分配、归一化和其他损失。S不能事后简化为随意选择常数2，也不按正负分别匹配。先明确初始化、种子、预算、成熟日程及原VAL规则是否两种回归背景均覆盖，再决定实施。普通C开关的四组配对重复可检验稳定性，但单独重复不能排除整体强度解释；若研究目标是几何独有增量，强度控制更直接。跨图隔离、新质量loss及候选后处理不与本项叠加，不依据已暴露TEST调系数。新对照若仍无几何独有且稳定的收益，应收窄C主张或简化方法，而不是为了维持模块数量继续扩大实验。

### 24.2 目标的实际实现与比较边界

### 26.5 两个S的合同检查

### 27.2 交付一：原帧对与共同帧对的DFR分解

DFR每个有效帧对为`100·|d_t−d_(t−1)|/d_(t−1)`，其中`d=sqrt(w²+h²)`；只允许同视频、相邻真实帧ID、两端均有GT和预测。缺输出重置连续性，不跨缺帧配对。共同有效帧对取两版有效集合交集，**不是分别删帧后把剩余帧重新相邻连接**。

设B／111原均值为`mB,m111`，共同均值为`cB,c111`，使用精确恒等式：

`m111−mB = (c111−cB) + [(m111−c111)−(mB−cB)]`。

第一项是共同帧对上的预测差异，第二项是帧对集合改变的均值效应。它是统计分解，不是训练机制因果分解。

1. **评价／导出：** 原评价36项复现、重新导出逐字节一致、共同帧对仍退化，无需修正原评价或替换原成绩。

3. **环境／历史现场：** CuDNN记录确有变化，完整初始化／输入流证据缺失，因此B与111不是已证实的严格历史复现。保留复现不确定性；不能为了达到B高分反复重跑，也不能把性能差异完全归于库版本。
4. **最终方法选择：** 若论文需确认C的可重复增量，等待之后统一安排的配对重复，不提前启动多种子。比较完整SymEOOD的C，配对110／111；比较几何差异化超出强度增强，选定回归背景后配对U／S／G。两域回归背景都需结论时才扩大六组。统一环境与入口，存完整初始状态、预训练／数据／输入流身份、计数与随机状态，固定预算，不只重跑111。

**B与111本身同属C开启的完整机制，二者差异不是C开／关消融。** 本节不能用于证明C有害、删除C，或用历史B较好反过来证明C有效。C仍保持“当前单次对照未显示跨域一致增益，可重复价值待确认”；不追认普遍协同，也不宣称普遍无效。
