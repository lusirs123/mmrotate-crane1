# S037后定向文献与机制选择（2026-10-19）

本轮仅定向检索、作者代码阅读及本地历史查重；不修改模型或实验代码，不安装、训练或运行作者模型。Exa两条问题主线共9次检索、49条返回条目（含重复，不等于49篇核读论文）。检索覆盖当前框与视觉证据匹配，以及分边定位；补查2024—2026关键词，不作穷尽或最新性保证。

## 1. 选择结果

优先保留一个**待适配审查的机制**：按当前旋转框Q对齐、保留二维位置布局的单尺度视觉读出。以S2A-Net的AlignConv为几何对齐参考，RefineBox为冻结检测器与当前框ROI接口参考。它不是已通过的训练候选，不是完整移植两个模型，也不保证准确边保护。

假设：S037已表明V利用部分图像绑定证据，但它在固定B-ROI位置读取特征、由Q参考向量提供条件。将视觉读取位置与Q对应，并避免过早沿边最大池化或全局平均，可能改善方向判断。该假设未被S037证明；固定ROI与Q不一起移动并不自动构成缺陷。

## 2. 文献和代码证据

### S2A-Net / Align Deep Features for Oriented Object Detection

- [论文](https://arxiv.org/abs/2008.09397)：2020预印本，后发表于TGRS。研究旋转anchor与卷积特征的对齐。
- [作者源码，固定提交e463c2bb17e161a6909e3d83410b49697dce770a](https://github.com/csuhan/s2anet/blob/e463c2bb17e161a6909e3d83410b49697dce770a/mmdet/models/anchor_heads_rotated/s2anet_head.py)。
- 实读`forward_single`、`AlignConv.get_offset`：从detach的refined anchor解码得到中心、宽高、角度；将标准卷积网格按框宽高缩放、旋转、平移，计算deformable convolution采样偏移。训练和推理都走对齐路径，偏移由当前预测几何确定，不需GT在线参与。
- 原法是完整旋转检测器，并有ORConv、分类/回归等其他部分；本项目只借其Q到采样坐标的机制，不能将原论文整网收益归于本项目适配。

### RefineBox

- [论文](https://arxiv.org/abs/2307.11828)、[作者仓库](https://github.com/YiqunChen1999/RefineBox)。仓库HEAD目录查询为0a9feb76857adb879225d536a92797d3f884522c；本次网页代码读取为master视图，不冒称逐文件SHA已绑定。
- 实读[res_refiner.py](https://github.com/YiqunChen1999/RefineBox/blob/master/refinebox/models/layers/res_refiner.py)：`pred_boxes`转图像坐标后进入`roi_layer(features, roi_boxes)`，再经残差块、平均池化、回归及框增量交付。
- 适合作冻结前端/框驱动ROI接口参考；原代码最终平均池化，不提供分边保护保证，也不是旋转框实现。多尺度、迭代及分类改动不直接纳入首选机制。

### PARDet（Pattern Recognition 2024）

- [论文](https://doi.org/10.1016/j.patcog.2024.110534)、[作者配置](https://github.com/Xuyihaoby/PARDet/blob/main/configs/PARDet/pardet_r50_fpn_1x.py)、[作者head源码](https://github.com/Xuyihaoby/PARDet/blob/main/mmdet/models/dense_heads/pardet_head.py)。本次读取main网页，未完成commit固定。
- 关键代码发现：`forward_single`在`not self.training`时直接返回`cls_score,bbox_pred`；点分支只在训练返回。`loss_single`中对预测点集拟合GMM，在中心位置采样分类/回归预测，结合GT内部位置选择和权重计算损失。
- 因此，公开实现不能当作现成的“推理时随当前Q重采样视觉特征”插件。GT用于训练并非错误，但将该训练机制改成在线模块需要新的设计。降为训练位置匹配参考，不作为本轮首选。

### SABL / BorderDet（ECCV2020）

- [SABL论文](https://arxiv.org/abs/1912.04260)、[MMDetection实现](https://github.com/open-mmlab/mmdetection/blob/cfd5d3a9/mmdet/models/roi_heads/bbox_heads/sabl_head.py)：方向注意力聚合、逐边特征及粗桶/细偏移。
- [BorderDet论文](https://arxiv.org/abs/2007.11056)、[作者head](https://github.com/Megvii-BaseDetection/BorderDet/blob/master/playground/detection/coco/borderdet/borderdet.res50.fpn.coco.800size.1x/borderdet.py)、[维护方BorderAlign算子说明与源码](https://mmcv.readthedocs.io/en/v1.3.15/_modules/mmcv/ops/border_align.html)：沿预测四边插值采样并最大池化。作者仓库说明其公开版本是基于cvpods的重实现。
- 两者已被本项目H/C使用作参考；分边分支不等于准确边自动保护。不得把再次加入沿边采样或桶回归作为新机制。

### Semantic-Aware Transformation-Invariant RoI Align（AAAI2024）

- [作者论文](https://cg.cs.tsinghua.edu.cn/papers/AAAI-2024-RoI-Align.pdf)：语义注意力选择区域、按ROI比例动态采样及Area Embedding。
- [作者仓库](https://github.com/cxjyxxme/SemanticRoIAlign)本次返回README仅标注“coming soon”，没有核验到可用核心源码。因此只保留位置/区域表示启发，不作为代码首选。

## 3. 与已做方案的真实区别

本地查重读取`port_geometry_size_boundary_v1.py`及`port_geometry_size_proposal_v1.py`。

- H/C已在缓存9×9特征上按框构造对边范围，并沿切向最大池化。
- 七槽代码已将Q传入`border_points`，会随Q改变采样坐标；所以“当前框改变采样位置”不是首次提出。
- S030/031检验过缓存与原生P3来源；所以“改用原生P3”也不是新机制。
- V的参考向量会随Q变，视觉网格保持固定。

首选方向能成立的待审查差异是：**同一特征来源下，以Q定义二维空间对齐，保留位置布局进入读出；与固定B坐标的同容量读出比较。** 不将Q对齐、换原生特征、分边新头、新loss、多尺度同时叠加。二维布局能否保留到有效决策阶段，以及与已有空间stem究竟如何不同，仍须画清数据流后才能形成合同。

## 4. 另一边保护和最小对照边界

本轮未找到可直接证明“只改错边、准确边不损伤”的可移植保证。SABL分边、AlignConv对齐、RefineBox精修都不能承担这一结论。因此保护是独立验收目标，不能用模块名称或结构分支替代。

若后续适配审查成立，最小对照应固定特征来源、读出容量、监督、预算、中性初始化和尺寸交付，只改变固定B坐标与Q对齐的读取方式。V20保留历史参照，不能单独充当新结构的公平控制。必须报告读取范围、支持与越界差异；若Q对齐扩大了视野，收益归因须包括覆盖变化，而不能纯称位置对齐效果。

GT只监督规范长短边，不将沿M轴的GT投影范围冒充规范边长，避免重犯S033的角度混杂。中心、角度、score、覆盖维持既定身份；near长短边、另一边损伤、a/r与双边10%同时评价。人工跨GT响应只作机制解释，自然完整VAL负责候选评价；TRAIN诊断不是跳过VAL的门槛。
