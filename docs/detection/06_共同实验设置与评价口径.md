## 1. 数据与阶段边界

- TRAIN为2558图（Real1810、Sim748），VAL887帧（Real375、Sim512），TEST1440帧（Real868、Sim572）。小头TRAIN另有1.0和0.5尺度视图，不作为新增独立图像。
- 当前新110及其下游链路各TEST版本均输出1431帧，缺9帧；VAL输出885帧，缺2帧。EOOD增强控制TEST输出1410帧、VAL882帧。缺输出不从全帧指标分母删除。
- 中心正确：中心误差＜15px；定位命中：RIoU≥0.5。全帧mean_RIoU对缺输出记0。
- 长／短边MAE：规范排序后的两边相对GT边长的绝对误差均值，乘100为%；按实际输出帧计算。联合正确：两边误差均≤10%，按全部GT帧计算。
- a为两边对数相对误差的均值，r为其差；表内abs-a、abs-r分别是绝对值均值，无量纲。联合正确数与比例误差是两项不同指标。
- 方向只报告Sim；原协议在缺输出或中心误差≥10px时给予90°惩罚。本文当前链路的Sim帧全部输出且中心有效，所列协议角度值与相应纯角度值一致，不扩展为Real角度精度结论。
- AP采用现有原生核对通过的单类VOC07十一点AP，非COCO AP@[.50:.95]。后续检测主表按§7明确为Top1任务OBB AP50／AP75，检测器原生完整输出另列，不与不同AP实现直接混称。
- 自定义时序指标见表1b：DFR为有效相邻输出框的对角线相对变化；ACI描述角度变化一致性，二者不单独证明几何正确或控制性能。MCML反映连续定位失败的最长长度，TDR_w10为10帧窗口至少命中一帧的比例，MRF为原协议定义的失败后恢复时间统计。完整定义见[链路指标总表](04_完整链路_TEST与深度估计指标.md)及原评价记录；方向、时序和尺寸精度分别解释。
- 检测器与两阶段头分别训练并冻结，不是整条链联合端到端训练。当前为单次运行；已暴露TEST仅用于固定版本工程比较，不称独立泛化或跨seed稳定性证明。

## 2. 尺度增强与训练流程

检测器训练阶段采用图像与OBB一致的等比例缩小：RResize后以0.5概率取s∈[0.5,1.0]，中心和双边同时乘s、角度不变，scale_factor累乘，随后保留原翻转、归一化与Pad。测试不使用此训练增强；没有额外引入拉伸、裁剪或新的光照方案。

检测器为ResNet50/FPN、24轮、seed0，原优化器／学习率／辅助头／分配日程以[冻结展开配置](../../work_dirs/symeood_110_retrain_seed0_20261026_v1/configs/Coff_seed0.py)和[训练协议](../../work_dirs/symeood_110_retrain_seed0_20261026_v1/protocol.json)为准。midpoint／LVSR冻结前端，从同源P3特征与当前框构造输入，正式缓存不等于额外模型；三阶段不是整条链联合端到端训练。

小论文三个固定epoch为20／21／11；大论文只将双分支尺寸头换为共享ep11。TEST不重选epoch、调阈值或改标定。历史各实验训练次数、随机性及选版沿革按自身记录，不用当前seed0将它们改写为统一多种子实验。

## 3. 中心的三个分母与图像几何

设总帧N、输出O、中心正确H：输出条件中心准确率=H/O；输出覆盖率=O/N；全帧中心正确覆盖=H/N。当前表使用正确数并标明全帧分母；若报告R_center须写清对应哪个分母，不直接改名旧终端字段。

尺寸相对误差按规范长、短边分别计算；MAE/P95/bias以输出为分母，双边均≤10%以全帧为分母，另列缺输出。abs-a和abs-r是双边log相对误差的共同尺度与比例分量，无量纲。中心正确使用＜15px，定位命中使用RIoU≥0.5，二者不能互代。

## 4. 时序、自定义方向与AP

DFR=100×mean(|d_t−d_{t−1}|/d_{t−1})，d为OBB对角线，只在连续帧号且两帧有输出时计算；它不是去除GT运动后的抖动残差。ACI为原协议角度变化一致性。TDR_w10统计窗口至少一次定位命中；MCML按各连续片段最长定位失败统计最大／均值；MRF按已恢复失败事件统计，未恢复尾段不混入。报告实际帧对、窗口、片段、事件分母。

角度以Sim为可靠评价域，协议惩罚与纯角度RMSE分别标识。AP为固定Top-1 OBB、单类VOC07十一点AP，非COCO AP@[.50:.95]。保留原分数和实际输出状态，不通过删帧获得精度改善。

当前五版EOOD／增强EOOD／110／M／双分支的共同CPU评价使用原始浮点框；旧导出文本取整摘要仍属历史口径，不覆盖。旧B/M原生VAL/TEST AP说明与命令见[公共历史原文](历史归档/共同设置与旧链路_完整原文.md#original-05-02)，相关证据目录保持原位。

- 全链路及模块组合主表统一采用**Top1任务OBB AP50／AP75**：所有方法在原生运行阈值／NMS后最多保留最高分一个抓斗框，再进行规定的下游处理；无输出保留为缺失，不能补框。计算沿用旋转框几何、单类匹配、VOC07十一点积分、原分数和分数排序。同一个任务目标规则适用于现有与后续外部方法，使用该先验需明确披露。

## 8. 指标含义、模块解释与更换110的影响（2026-10-29）

本节解释既定指标和后续实验依赖，不修改公式、现有评价结果、原选版及权重身份；不授权任何训练或新TEST。

### 8.1 主指标表达什么

| 指标 | 定义及分母 | 对本课题的意义 | 解释边界 |
|---|---|---|---|
| Top1 OBB AP50 | 旋转IoU≥0.5作匹配，按保存分数排序得到PR曲线，VOC07十一点积分；全部GT进入召回分母 | 综合衡量任务输出的检出、误检、定位及置信度排序；0.5为较宽松框匹配要求 | 不是某个固定阈值下的准确率或Recall；评价前的原生分数阈值仍然保留。单类AP=mAP；Top1先验必须说明，不代表完整多候选输出或空场景验证 |
| Top1 OBB AP75 | 与AP50完全相同，仅匹配阈值为旋转IoU≥0.75 | 更严格地衡量有向框整体是否贴合目标，对中心、角度及尺寸误差均有反应 | 不能将变化单独归因于方向或某条边；不同长宽比对同样角差的IoU响应不同。数值是百分点，不把百分点差与相对增幅混写 |
| Recall@RIoU0.5 | 固定运行阈值下旋转IoU匹配TP／全部GT数；本项目当前单GT、Top1下等于定位命中数／帧数 | 目标有多少被框正确覆盖，反映漏检及严重定位失败；区别于输出数量和中心正确数 | 有框不等于匹配成功；中心接近也不等于IoU达标。不能仅报Recall而忽略框精度或误检；不根据TEST重选分数阈值 |
| 中心MAE(px) | 输出框中心与GT中心欧氏距离的均值，按实际输出帧；不要求先满足IoU或15px中心正确 | 表达可用预测的中心定位精度，对应midpoint的中心精修目标 | 属于有输出条件下的误差，漏检不被自动惩罚，必须同时看Recall／输出数；不同输出集合的均值不是完全相同样本上的因果比较。不是三维位置或测距误差 |
| Sim纯周期角度RMSE(°) | 规范长边方向差按180°周期取最小角差，再求平方均值平方根；分母为实际有输出的Sim帧 | 描述图像平面长轴方向精度，平方项使较大方向偏差影响更突出 | 当前只用可靠Sim方向真值；不混入90°中心／缺输出惩罚，不扩展成Real方向、三维姿态或物理摆角的精度结论 |
| 长边相对MAE(%) | 规范排序后平均100×abs(预测长边／GT长边−1)，按实际输出帧 | 描述长边图像尺寸的平均相对偏差，专门评价LVSR的该边修正 | 绝对误差不区分偏大／偏小，均值不体现尾部；需要解释时看已有bias／P95。不代表短边或测距同时改善 |
| 短边相对MAE(%) | 与长边定义相同，改用规范短边，按实际输出帧 | 描述短边相对精度；不因长边误差下降而掩盖短边代价 | 不用单边改善替代双边协调；同样属于有输出条件下的误差 |
| 双边尺寸达标率(%) | 同一帧长、短两边相对误差同时≤10%的数量／全部GT帧数；缺输出为未达标 | 同时约束两条边，可用来检验单边均值收益是否转化为双边达标 | 不是长短边比例误差，也不包含中心、方向或IoU成功条件；10%为既有评价阈值，不是已验证工程容差；与MAE可因阈值附近分布而出现不同趋势 |

AP50／AP75都属于OBB检测指标，不是仅因使用旋转框就另造的新指标；差别来自IoU几何和匹配阈值。现有VOC07十一点积分中，若最大Recall＜1，则Recall=1的采样点精度为0，上限不超过约90.9091%。当前AP50接近该上限，不能将90.9误读成数据或计算错误，也不能根据很小的AP50差认定稳定优势。AP75、固定运行点Recall和几何误差分别补充解释，不更换积分来追求更好数字。

分域结果作为同一实验的子集报告，不是独立重复；本项目现有单次训练与相关视频帧不能支持统计显著性或跨seed稳定性结论。全帧Recall和双边达标率保留漏检代价，MAE展示输出几何质量，两类分母有意不同，表注应明确，不通过删帧让均值更优。

同样加入M、L后，两条完整流程E＋M23＋L17→110＋M21＋L11，AP75提高0.2140个百分点、Recall提高1.3194个百分点、双边达标提高2.9861个百分点，同时中心和长边MAE更差。该结果可提示底座的链路价值，但两条流程各自训练、选择小头，不能把所有差异单独归因于110。E＋L17等简单竞争方案必须保留；后续是否采用完整链路按任务目标与完整证据判断，不以模块数量决定。

### 8.3 以后优化110，需要重做哪些内容

本项目midpoint输入含检测框和P3局部ROI／支持区域；LVSR还依赖midpoint输出及相应参考框。即使检测器结构不变，新权重也可能改变P3、框、分数和ROI采样。**新110不能继承旧110→M21→L11的指标，旧缓存也不能默认属于新前端。** 历史缓存与权重保留作为旧版本证据，不覆盖。

| 实际变化／阶段 | 是否需要新训练 | 是否需要新推理或评价 | 可以复用什么 |
|---|---|---|---|
| 只改文档、表格或从同一保存预测计算指标 | 不需要 | 有保存字段时仅CPU重算，不重新前向 | 原预测、原权重、原缓存、既有已通过检查 |
| 训练出新的110，先判断前端本身 | 新110本身需训练；此时不必训练M／L | 按冻结规则先做新110的完整VAL；旧版本性能不能直接沿用 | 数据与划分、已有增强／优化器及评价入口；E控制不变时原结果继续作已保存控制 |
| 用新110接固定旧M21／L11，测试迁移适用性 | 可以先不重训小头 | 先在新前端实际特征／框上做完整VAL，记录为新的组合与身份；不能仅用旧缓存回放代替新前端前向 | 旧小头结构和权重可作固定迁移候选，但没有性能保持保证，当前锁定入口是否支持该新组合需另行实现 |
| 固定旧小头不适配，或目标是每个前端分别训练的公平比较 | 需在新前端上重新训练相应M／L；若M改变，下游L亦需重新适配和验证，通常需重训 | 为所需TRAIN／VAL重新提取新前端缓存并按原流程训练、VAL选版 | 旧训练器、网络定义、数据顺序与协议尽量复用；不默认继承旧头状态或续训 |
| 确定采用新的最终链路 | 不一定额外训练，取决于上一阶段 | 对新110及论文要引用的新增组合按冻结选版统一执行TEST；若报告速度，重新测量该实际链路。不能继承旧版TEST | 未变的E等控制及历史失败结果，不必因此重跑所有旧候选、CP、C续训或八组消融 |
| 同时改变A／B方法定义、结构或关键超参 | 依修改范围决定，不以旧同名方法代替新方案 | 新主张涉及的直接消融需针对性补齐；旧A／B四格仍只对应旧方案 | 可复用未变实验材料，但不能声称旧消融已严格验证修改后的公式 |
| 新链路还要用于大论文测距 | 小头是否重训按适配结果决定 | 新链路若用于测距结论，需要重新生成相应序列预测并沿用固定公式／标定评价；小论文本轮无须自动做 | 原测距代码与固定标定。旧大论文冻结基底不受新候选自动替换 |

最省预算的条件路径为：**新110完整VAL→与当前110／E的主指标和代价对照→值得继续时，固定旧小头在新前端上做VAL迁移检查→只有需要时才重建完整TRAIN缓存和重训小头→冻结版本后执行所需组合TEST。** 若前端VAL没有值得保留的收益即可停止，不先把后续链路全部重做一遍。该路径是未来建议，本次未运行任何环节。

新开发决策依据TRAIN／VAL和预先固定的目标／容差，已多次暴露的TEST只作冻结版本比较，不用来反复挑新110、重选小头epoch或调参数。优化后仅替换论文确实使用的链路与受影响直接消融，不必重新执行整个历史研发过程。
