### 2.5 继续优化尺寸的检测动机与成功边界（2026-10-16）

**当前研究问题：已检出抓斗的旋转框仍存在精定位不足。** 长短边决定预测框的覆盖范围；其偏差会与中心、方向误差共同影响最终RIoU。因此，继续研究尺寸回归的直接目的，是提高旋转框定位质量，为小论文提供检测收益证据。深度估计留待大论文验证，不作为本轮研究动机或成功条件。

已有M的完整VAL中，53帧处于`0.5≤RIoU<0.75`，其中Real seq07为50帧、Sim为3帧。过程记录[S005.3](尺寸优化专用记录_20261016.md#activity-s005)的离线分量替换显示：仅用GT长短边替换预测尺寸、保持预测中心和方向，53帧中52帧达到RIoU≥0.75（Real49帧、Sim3帧）。这支持尺寸误差是该组严格重叠不足的重要影响因素；这是GT敏感性诊断，不是可实现收益、唯一根因证明或新候选成绩，也不支持按GT选择在线修正规则。

| 层次 | 当前定位 |
|---|---|
| 研究问题 | 普通有效输出仍存在框范围偏差与严格重叠不足 |
| 拟研究手段 | 改善长短边及共同尺度估计，检验其能否提高最终旋转框定位质量；尚未确定具体新方法 |
| 直接目标 | 长短边连续误差下降，检查共同尺度／投影比例及系统性偏差；用MAE／P95／bias、a／r验证 |
| 正确观测保护 | 核对原本准确框的变化、错→对／对→错及全帧尺寸正确覆盖，避免单向纠错和整体缩小 |
| 检测采用依据 | 全帧mean_RIoU等既有检测指标体现可用定位收益，AP补充；RIoU上升不能代替尺寸直接目标 |
| 附带代价 | 中心、方向、覆盖及连续失配检查退化；可维持原水平，不要求同步改善；允许的代价须事先明确，完整报告总体、两域和逐视频 |

可用于小论文研究动机的表述：

> 现有方法已改善抓斗检测与旋转框定位，但部分有效检测仍存在框范围偏差。长短边估计误差会降低预测框与目标标注的重叠，限制精细定位。因此，进一步研究尺寸回归，以提高最终旋转框定位质量，并保护检测覆盖与连续性。

本方向称为“面向旋转框精定位的尺寸回归优化”，与已完成的训练尺度增强B区分。它可以聚焦普通输出精定位，不要求同时解决所有检测失败；seq07的无输出与严重中心错位另行报告，不宣称尺寸修正能够补回漏检或修复全部连续失配。本轮优化的是相对现有GT的二维长短边回归精度／标注框范围一致性；真实短边按视频固定比例生成，缺少逐帧独立测量。回归改善不证明物理尺寸、真实可见轮廓或深度精度更准确，也不自动转成重标注任务。

若仅长短边误差下降，而RIoU等任务指标没有可用收益，则记录为局部几何结果，不优先作为小论文主要新增改进。候选仍须经过历史查重和TRAIN支持核对，事先固定主指标、保护要求及可接受代价；本节不自动恢复S004、方向平衡或其他旧实验，也不构成训练授权。

## 4. 标注合同：生成一致，物理参考未确认
