# 外部OBB对比与效率核查（2026-11-01）

**结论：外部对比的实际工作就是用其他OBB检测模型，在同一个抓斗数据集上训练、VAL选权和TEST评价。** 本轮核查只用于判断已有结果能否复用，不把核查细节变成额外实验。当前第一步只需补一个独立检测器，不要求给它做内部消融、接Midpoint/LVSR或运行模块全排列；一个外部模型是最小补充，不代表足以支撑通用领先或保证投稿通过。

## 2. 外部对比实际只需做什么

1. **选一个独立OBB检测器。** 最小实施候选为Oriented R-CNN R50/FPN：本仓库已有[通用配置](../../configs/oriented_rcnn/oriented_rcnn_r50_fpn_1x_dota_le90.py)，官方也提供相应[MMRotate配置](https://github.com/open-mmlab/mmrotate/blob/main/configs/oriented_rcnn/oriented_rcnn_r50_fpn_1x_dota_le90.py)。这是根据现有实现可复用性作出的建议，不是最新模型排名，也不是已通过运行验收。
2. **在当前数据上训练。** 改为单类grab和当前TRAIN/VAL/TEST路径；采用相同1024输入、训练尺度增强及现有24轮对照预算。保留该检测器自己的RPN、RoI、损失等方法结构，不把它改造成EOOD。官方DOTA配置的15类、12轮日程、学习率和Pad设置不能直接当成本项目已对齐设置。
3. **只在VAL上选权重，再运行一次固定TEST。** 最小方案复用既有五候选16/18/20/22/24与原任务选权规则，说明它不是按最高AP选版。若另设标准检测AP选版比较，应提前统一协议，不根据TEST挑版本。训练批量、预训练来源和实际调度在配置中记录即可，不增加对应消融。
4. **用共同入口算指标。** 主表沿用[共同评价口径](06_共同实验设置与评价口径.md#ap-display-freeze)：Top1 OBB AP50/AP75、Recall、RIoU及任务中心/尺寸指标，Real/Sim分别留表。保存原生完整输出；另算原生完整检测AP时明确标识，不能将多框AP与Top1 AP混称。外部模型无需连接M/L。

“在数据集上运行”包含训练和评价；直接拿DOTA等其他数据集的预训练检测权重测试，只能得到迁移推理结果，不能替代当前所需的同划分训练对比。初始化可使用与当前模型一致来源的ImageNet骨干，具体字节在实施时核对；不用旧RetinaNet权重续训来充当新公平实验。

公平性检查应融入配置准备和正常运行记录，不另立大量实验。显存适配先检查真实批次；若默认两卡各batch2无法在显存限制内运行，再明确有效batch和更新预算如何保持，不以降低外部模型训练预算制造差距。本轮未运行该检查，不能预先保证两阶段模型显存足够。

## 3. 效率是另一项小工作，不需要重训

对固定EOOD、R4、R4＋M20、R4＋M20＋L5在同一硬件、batch1、同一输入和精度下，直接测推理时延与显存，并统计参数量即可。外部模型训练完成后可在相同条件下加一行。参数量注明是否包含仅训练辅助头；不能仅凭两个小头参数少就推断完整系统轻量或实时。

沿用旧计时方法区分“解码图像到最终OBB”与“模型及后处理”，包含完整M/L局部采样、解码与回退；P3从本次检测器前向复用，不能拿预先缓存特征代替整链推理。记录warmup、CUDA同步、均值/P50/P95及显存，不将文件读取、评估器、CPU指标分析或相机显示混作模型时延。旧工具默认固定旧权重和旧四组身份，不能直接运行后改标签冒充新链路。

该项缺少的是**当前版本直接测量**，不需要重新训练模型。既有整次TEST总耗时或训练显存不能代替统一计时。

## 4. 收尾清单

| 优先级 | 下一步 | 是否需要新训练 |
| --- | --- | --- |
| 首先 | 适配一个独立OBB检测器，当前数据训练→固定VAL选权→TEST共同评价 | 是，最小先一组 |
| 随后或并行 | 当前四组完整流程的统一时延、显存与参数量 | 否 |
| 写作同步 | 将当前四组主结果、SGAR内部对照和外部结果写入相应表格，保留取舍 | 否 |

不把SGAR、Midpoint、LVSR的全部内部拆分或多种子重跑加入本次清单。模型开发已固定；是否增加其他外部模型或独立泛化证据，应结合最终论文主张与首个有效对照的覆盖范围判断，不能根据TEST输赢反复更换比较对象。

本轮只完成本地/服务器只读核查及本地记录：没有加载权重执行、没有GPU推理、训练、改选权、安装软件或修改论文正文。服务器四份当前权重SHA已核实，现有最终链路保持。机器可读结论见[核查摘要](../../work_dirs/external_comparison_audit_20261101_v1/audit_summary.json)；旧效率原始材料见[旧计时收据](../../work_dirs/port_detection_runtime_v1/four_arm_fix5_20261006_105204_491124/benchmark/runtime_compare.json)。
