## 2. 外部对比实际只需做什么

本节保留初始实施建议；实际采用的完整 FAA（Oriented R-CNN，R50）及最终双卡设置以[第5节](#faa-adaptation-record)为准。

1. **选一个独立OBB检测器。** 最小实施候选为Oriented R-CNN R50/FPN：本仓库已有[通用配置](../../configs/oriented_rcnn/oriented_rcnn_r50_fpn_1x_dota_le90.py)，官方也提供相应[MMRotate配置](https://github.com/open-mmlab/mmrotate/blob/main/configs/oriented_rcnn/oriented_rcnn_r50_fpn_1x_dota_le90.py)。这是根据现有实现可复用性作出的建议，不是最新模型排名，也不是已通过运行验收。
2. **在当前数据上训练。** 改为单类grab和当前TRAIN/VAL/TEST路径；采用相同1024输入、训练尺度增强及现有24轮对照预算。保留该检测器自己的RPN、RoI、损失等方法结构，不把它改造成EOOD。官方DOTA配置的15类、12轮日程、学习率和Pad设置不能直接当成本项目已对齐设置。
3. **只在VAL上选权重，再运行一次固定TEST。** 最小方案复用既有五候选16/18/20/22/24与原任务选权规则，说明它不是按最高AP选版。若另设标准检测AP选版比较，应提前统一协议，不根据TEST挑版本。训练批量、预训练来源和实际调度在配置中记录即可，不增加对应消融。
4. **用共同入口算指标。** 主表沿用[共同评价口径](06_共同实验设置与评价口径.md#ap-display-freeze)：Top1 OBB AP50/AP75、Recall、RIoU及任务中心/尺寸指标，Real/Sim分别留表。保存原生完整输出；另算原生完整检测AP时明确标识，不能将多框AP与Top1 AP混称。外部模型无需连接M/L。

“在数据集上运行”包含训练和评价；直接拿DOTA等其他数据集的预训练检测权重测试，只能得到迁移推理结果，不能替代当前所需的同划分训练对比。初始化可使用与当前模型一致来源的ImageNet骨干，具体字节在实施时核对；不用旧RetinaNet权重续训来充当新公平实验。

公平性检查应融入配置准备和正常运行记录，不另立大量实验。显存适配先检查真实批次；若默认两卡各batch2无法在显存限制内运行，再明确有效batch和更新预算如何保持，不以降低外部模型训练预算制造差距。本轮未运行该检查，不能预先保证两阶段模型显存足够。
