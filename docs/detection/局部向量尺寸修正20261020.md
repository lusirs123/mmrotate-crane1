## 1. 创新性判断与定位

**当前判断：具备作为第三个研究模块的完整内容，但尚不足以稳妥宣称为已经充分验证的独立方法创新。** 当前有明确的数据流、2800参数实现、完整冻结评价及局部正结果；S046—S049已补齐直接回归对照：单阶段未显示统一结构优势，两阶段LVSR在Sim与Unknown表现更好，但不同起点流程不等于纯结构归因。剩余缺口是新颖性定位、稳定性与独立泛化，而非尚未实施结构对照。性能收益和技术新颖性是两个问题：有Sim收益不自动证明新颖，存在结构差异也不自动证明更有效。

建议以“基于局部向量读出的旋转框尺寸修正”为第三研究点标题。方法主体采用C对应的结构与原尺寸监督，R为比例监督消融。C6是固定实验代表，不因本次写作成为正式采用版本。A20是其共同训练阶段权重，不是需要再次拼接的模块；正文无需单独把A20写成创新，但实现细节与补充材料必须保留训练沿革。

**核心技术内容可概括为一个整体设计：** 以当前旋转框为几何参考，在局部二维视觉特征上预测对边向量残差，先恢复原图坐标尺度，再形成长短边估计，通过支持加权和中性参考归一化实现尺寸专用修正。中心、方向、分数及输出身份由交付结构保持。

这个整体设计包含三个相互衔接的技术环节，不拆成三个独立创新：


| 技术环节                     | 实际实现                                            | 可说明的作用及边界                                         |
| ------------------------------ | ----------------------------------------------------- | ------------------------------------------------------------ |
| 当前框条件下的局部二维读出   | 固定B-P3特征、逻辑位置、M参考向量共同进入小型卷积头 | 保留邻域布局与当前框条件；不等于视觉特征按Q重新对齐        |
| 原图尺度下的对边向量解码     | 先逆ROI/实际resize变换，再取对边向量差的长度并排序  | 按实际坐标合同恢复规范尺寸；不保证预测潜向量是真实可见中点 |
| 中性参考归一化及尺寸专用交付 | 支持加权均值相对同支持中性尺寸取比，只更新尺寸      | 零残差保持M，其余字段身份保持；不保证准确长短边不受损      |

“冻结前端后接精修头”已有RefineBox先例；局部回归、旋转框几何表示和支持聚合也不能笼统声称首次提出。本项目应主张具体任务下的尺寸专用设计与实证分析，而不是把现成组件的组合直接等同于原创算法。Q对齐是另一已测候选，不能将其机制归给固定B的C/R。比例监督和退步保护尚无稳定新增联合收益，不能作为当前主要创新依据。

## 2. 引言贡献句与研究动机（正文候选）

**贡献句，当前可用的保守版本：**

> 我们构建了一种以当前旋转框为参考的局部向量尺寸读出模块，在固定中心与方向的条件下进行长短边修正，并通过同预算监督对照与冻结下游评价，分析尺寸精度、投影比例和测距误差之间的收益与取舍。

该句描述已完成的方法与研究贡献，不宣称首创、全面优越或准确边保护已实现。现有对照支持有限流程优势，不支持局部向量解码的普遍必要性；不得加入“显著优于直接回归”等无范围结论。

**动机段：**

> 旋转框的中心和方向改善并不必然带来准确的长短边估计。尺寸误差既影响定位重叠，也会通过短边尺度和投影比例传递到单目测距。与此同时，两条边的修正可能发生取舍：一条边误差降低时，另一条原本准确的边可能被改坏。因此，本研究将尺寸修正作为独立输出分量，在保持已有中心与方向的条件下，考察局部视觉证据能否改善两条边的估计，并同时评价连续尺寸误差、双边达标率和检测性能。

## 3. 方法（正文候选）

### 3.1 输入与局部表示

设冻结检测器B提供局部特征，M表示其后已有中点几何处理的输出。尺寸头读取固定B坐标下的P3局部特征F∈R^(256×9×9)，并使用逻辑网格位置u_i及由M构造的四个参考向量。四个向量对应M矩形的四边中点相对逻辑位置的位移，仅作为几何参考。C版本不使用真实中点监督，因此输出应称为潜在局部向量，而不是已识别的实体边界点。

固定B版本沿用对齐对照中的共同支持W=min(S_A,S_Q)。其中S_A为固定B网格支持，S_Q为按B→Q映射得到的支持，Q为自然M框；该支持不使用GT。W=0的槽位屏蔽视觉输入，W>0位置按原定义保留采样值。因此，虽然C的视觉取值来自固定B网格，仍保留Q相关支持计算，不能将其简写为完全无Q依赖的普通ROI回归头。

将256维视觉特征、1维支持、2维位置和8维参考向量拼接为267通道。网络由1×1卷积267→8、ReLU、3×3卷积8→8、ReLU及1×1卷积8→8组成，共2800个可训练参数。网络在81个位置分别输出四个二维向量残差：

$$
\hat v_{ik}=v^0_{ik}+\Delta v_{ik},\qquad i=1,\ldots,81,\quad k=0,\ldots,3.

$$

末层权重与偏置初始化为零。检测器、M以及输入特征冻结，仅更新尺寸头。

### 3.2 对边尺寸解码与支持聚合

令A为实际ROI向量到原图向量的线性变换，包含旋转、ROI尺度及实际非等比resize的逆变换。先计算原图向量，再求对边差的长度：

$$
\ell_{i,1}=\|A(\hat v_{i0}-\hat v_{i2})\|_2,\qquad
\ell_{i,2}=\|A(\hat v_{i1}-\hat v_{i3})\|_2.

$$

逐位置按长短排序得到d_i=(l_i,s_i)，然后进行支持加权：

$$
\bar d=\frac{\sum_i W_i d_i}{\sum_i W_i}.

$$

该顺序避免把非等比缩放后的向量范数直接当作原图长度。对参考向量v^0使用相同解码与支持得到\bar d^0，规范尺寸残差为

$$
\delta=\log(\bar d/\bar d^0).

$$

再按继承的raw轴及ROI轴身份映射到原交付接口。零向量残差使\bar d=\bar d^0，从而保持M尺寸。局部估计全部参与既定支持加权，不增加GT筛点或学习质量门控。非有限、退化或无有效支持时沿既定规则回退，回退保持不计为模型纠错成功。

### 3.3 尺寸监督与比例对照

原目标C采用最终两维log尺寸残差的SmoothL1监督，beta=0.1；监督目标为同轴身份下的log(GT尺寸/M尺寸)。R共享网络、解码、起点和预算，仅额外增加0.25倍的比例监督。比例误差定义为

$$
r=\log(l/l_{GT})-\log(s/s_{GT}).

$$

实际比例项为逐样本SmoothL1(r,0)，beta=0.1，再按batch取均值；R的总目标为L_size+0.25L_ratio。不将“长短边MAE均值差”作为该损失，也不要求图像投影比例等于物理尺寸比例。C/R不加入完整GT姿态监督，不在推理时读取GT、误差类别或视频域标签。

**训练沿革。** 两个版本从相同A20权重开始，以相同优化器初始化规则、数据顺序及6轮预算继续训练；C6和R6为原VAL规则得到的固定描述性代表。A20是阶段起点，并非推理时先运行的另一尺寸头。虽然原训练阶段共有24轮，续训起点是其中ep20，不能简单写成“ep24接着训练6轮”。两臂均未通过原VAL采用条件，后续TEST未用于重选权重或更改该身份。

### 3.4 方法数据流

```text
冻结B检测器 ── B-P3局部特征/源支持 ── 固定B视觉读取 ─┐
冻结M输出 ─── 参考向量/轴身份 ───────────────────────┤
B、M与元数据 ─ 共同支持W/逻辑位置 ───────────────────┘
  → 2800参数二维读出 → 局部向量残差
  → 实际原图变换 → 对边距离 → 局部长短边
  → 支持加权 → 中性参考归一化 → 尺寸交付
  → 保持M中心、方向、score及输出身份
```

## 6. 讨论与结论（正文候选）

> 本研究表明，在冻结已有中心与方向处理的条件下，局部向量尺寸读出可以取得仿真域的双边精度与定位收益，并在固定测距序列上降低平均米制误差。但这种收益未能跨域一致保持，准确边仍可能受损。比例监督虽略微降低平均比例误差，其额外测距收益有限，且未同步改善所有尺寸与定位指标。因此，尺寸修正应同时考察单边误差、双边达标、比例和下游传播，而不能以某一个平均指标替代整体判断。

### 11.3 本地代码核查与真正剩余的差异

核读[local_vectors](../../crane_project/utils/port_size_local_vectors_v1.py)的encode/decode/forward、[qalign](../../crane_project/utils/port_size_qalign_v1.py)的read_pair/size_loss及[structure](../../crane_project/utils/port_size_structure_v1.py)的DirectSizeHead：

1. **当前框条件的尺寸专用潜在解码。** 每个槽位输出四个二维残差，叠加M中点参考向量；逆实际非等比坐标变换后，取两对相对向量之差的范数，再局部长短排序、支持均值、中性参考比值交付。这是LVSR可明确描述的组合差异，不等于每个步骤各为创新。
2. **姿态保留是输出约束。** 仅更新尺寸，避免直接改写已细化的中心/角度；不保证尺寸不受姿态条件影响，更不保证准确边不被改坏。逆resize后求范数是正确几何实现要求，不宜单独包装为新算法。
3. **C的向量是潜在变量。** 实际采用的qalign.size_loss只监督最终尺寸；不能称预测了可信真实边界或空间位置。几何loss曾存在于其他臂，不属于当前C。零末层与中性参考保证初始重放M，是残差工程性质而非全程无损保护。
4. **W仍依赖Q。** 固定B读取共用W=min(S_B,S_Q)，不是GT前景、可学习置信度或新视觉信息；不能把已失败Q对齐机制归给LVSR固定B流程。
5. **D也是密集局部读出。** DirectSizeHead在同81个槽位预测两维log尺寸修正，然后按W聚合，不是“全局池化后两个标量”的弱基线。V/D差异含8维向量到范数/排序/尺寸域均值再取log，与2维log域均值的整体差别，不能单独归因“保留局部空间信息”或某个解码算子。

### 11.4 从实现直接推得的可辨识性边界（数学分析，不是新实验）

令槽位坐标为u_i，M参考中点为q_k，预测残差为Δv_ik，则v_ik=q_k-u_i+Δv_ik。对边差为

`v_i0-v_i2 = q_0-q_2 + Δv_i0-Δv_i2`。

槽位坐标u_i在对边差中抵消。若给同一对向量都加同一个二维偏移，其尺寸解码不变；仅尺寸监督无法唯一确定这些端点的位置。原图对边差同时旋转也可保持范数。**因此尺寸准确不能证明网络学会了真实边界位置或真实方向。** 输入仍含位置、视觉特征，故这不等于空间信息无用，也不等于D/V数学等价。

可合理将LVSR理解为“带几何解码约束的潜在尺寸参数化”。它可能形成有益归纳偏置，但S046单阶段结果未显示统一优势，S049不同起点流程也没有单独识别这一归纳偏置的因果作用。该限制应先澄清，不通过改名称将其升级为空间边界识别机制。

### 13.5 评价公式及不可混用口径

设规范长短边为l、s，GT为l*、s*。边误差e_l=l/l*−1、e_s=s/s*−1；边MAE为mean(abs(e))×100%，bias为mean(e)×100%，均按有输出帧统计。双边尺寸达标要求abs(e_l)≤0.1且abs(e_s)≤0.1；同时保留“正确/输出”与“正确/全帧”，缺输出不当正确。

对数误差u=ln(l/l*)、v=ln(s/s*)；**a=(u+v)/2，r=u−v**。报告meanabs(a)、meanabs(r)，无量纲且不乘100；长短边MAE数值接近不等于逐帧比例协调。near集合固定由M单边误差≤3%定义，各版本不重分组。

中心正确为欧氏距离严格<15px；方向按180°周期的最小角差≤3°，分母仅GT长短比≥1.2的输出。全帧mean_RIoU将缺输出记0；AP50/AP75沿用原生VOC2007 11点插值及原输出/置信度口径，不改成COCO AP。

时序指标按连续帧段统计，缺输出或帧号间断不跨越建立有效邻接：DFR为相邻输出框对角线变化abs(d_t−d_(t−1))/d_(t−1)的均值×100；ACI为clip(1−周期角差/(35°+数值保护),0,1)的均值。TDR为长度10的连续窗口内至少一次RIoU≥0.5的窗口比例；MCML为连续未达到该命中条件的最大长度，并报告各连续段最大长度的均值。总体DFR/ACI按有效邻接数加权，MCML均值按段数加权，TDR累加命中/窗口分母，不对各视频百分数直接平均。精确实现及浮点保护见[离线评价器](../../crane_project/tools/eval_crane_offline.py)与[总体聚合](../../crane_project/tools/analyze_port_size_proposal_downstream_v1.py)。此处沿用历史字段名称，不表示本系统采用EKF或PLC输入。

Raw-opt保持原像面与相机内参。规范长轴角γ，物理长短边L_G、S_G，定义：

```text
s_L = l * sqrt((cos(γ)/fx)^2 + (sin(γ)/fy)^2)
s_S = s * sqrt((sin(γ)/fx)^2 + (cos(γ)/fy)^2)
Z_L = L_G / s_L; Z_S = S_G / s_S; q = ln(Z_L/Z_S)
Z_hat = c * Z_S * exp(beta * q^2)
c = 1.0044577340905951; beta = 20.682289543661955; offset = 0
```

真值为抓斗参考中心相对物理相机的光轴深度`z_cg_opt_m`，不是欧氏距离。Unknown相机/物理尺寸原值保存在清单`data_identities`，标定文件内容及SHA保存在`calibration`。不新增q截断、有效帧筛选、偏移或标定拟合。

令E=Z_hat−Z_gt：MAE=mean(abs(E))，RMSE=sqrt(mean(E²))，bias=mean(E)，AbsRel=mean(abs(E)/Z_gt)。P95按排序位置(N−1)×0.95线性插值。米制指标与AbsRel分开单位，覆盖与共同有效帧同时报告；公式传播项只解释有符号偏差，不当作MAE可加分解。实现见[深度公式与指标](../../crane_project/utils/port_midpoint_depth_v1.py)，参数见[固定标定](../../crane_project/configs/depth_scale_calibration_obb_raw_opt_short_q2_train03_v1.json)。
