**1. 固定链路与一项结构候选。** 记M为封存B24＋σ1.5／ep03的最终原图输出（含原有回退）。冻结B全部参数／buffer及σ1.5头；两者eval、no_grad，新支路只读detach的输入。复用原B对齐P3 ROI，不重新取ROI、不改变采样context、σ或图像变换。

建议唯一初始结构为：`ROI256＋support1＋固定局部x/y2 → Conv1×1(259→8,bias) → ReLU → Conv3×3(8→8,pad1,bias) → ReLU`。沿垂直于每条ROI轴的维度取均值，分别得到8×9的u／v轴轮廓，保留轴上的9个位置。每个轮廓拼接相同的4个冻结几何量，进入各自`Linear(76→1,bias)`，得到δu／δv。两条末层权重和bias均置0；新卷积层按固定seed1703初始化。

4个几何量为`log(Mu/Bu)、log(Mv/Bv)、log(B_model,u/context_u)、log(B_model,v/context_v)`，其中u／v明确沿缓存ROI的模型B规范轴，M及原图B边长按该轴的raw索引关联。它们均来自当前冻结输入，无GT／域／序列／未来帧信息。参数推算为2080＋584＋154＝**2818个新可训练参数**；没有实测速度、显存或效果。轴轮廓是本次固定的一种尺寸读出选择，不扫描hidden宽度、池化方式或其它结构。

**2. 原图输出与梯度合同。** 将ROI轴残差按固定模型B的swap掩码映射回raw δw／δh，在原图直接构造：

`C＝(cx_M, cy_M, w_M·exp(δw), h_M·exp(δh), θ_M, score_M)`。
