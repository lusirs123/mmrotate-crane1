# TikZ 科研绘图

用于框架图、机制图、流程图、几何关系及图源修改。数据图优先使用适合数据的绘图库。先确认表达对象、输入、图幅、文字与交付格式；核查项目图源、符号、字体与配色，按语义安排节点与箭头。使用 standalone/TikZ，中文通常需 xeCJK 配合 XeLaTeX 和可用 CJK 字体；不要假定 Songti SC 在所有系统存在。

用 positioning、anchor 等建立相对布局；精确几何按坐标与计算约束。避免非等比缩放导致圆形或角度变形，箭头缩短优先使用 shorten；确保文字不穿线、节点不遮盖，检查长公式、局部密排、子图对齐与缩放后字号。分阶段编译并查看整体及局部；PDF 文本盒可能重叠但墨迹未重叠，也可能漏报线穿字，须结合渲染检查。

交付可编辑 tex 和 PDF；按需要用现有工具额外输出 PNG/SVG，说明实际工具及未完成项。保持图中文字、公式和实际方法一致；示意比例若非实测需标明。
