# LaTeX 编译诊断

先定位主文件、现有 recipe、编译命令、日志与依赖。依据首个实际错误区分语法、宏包、字体、引擎、图片、交叉引用与文献问题，先修根因再复编译。fontspec/xeCJK 常用 XeLaTeX 或 LuaLaTeX，具体以项目配置为准。

终端可执行而编辑器报 ENOENT 时检查编辑器进程的 PATH、latexmk 的子进程及 recipe；仅把 latexmk 配成绝对路径未必能找到其子工具。检查项目级 latexmkrc 和编辑器构建选择；保留用户配置，优先做局部修复。biber/BibTeX 问题检查主文件、工作目录和 bib 路径。清理生成物前明确范围，保留原文件与用户结果。按原入口重新构建，报告错误和验证状态。
