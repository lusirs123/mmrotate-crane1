# 参考文献与引用核对

先识别 BibTeX 或 biblatex/biber，读取实际主文件的 bibliography/addbibresource、样式和相关 bib。解析正文及被包含章节中的 cite 系列命令，按实际命令处理多键、可选参数、nocite 和自定义引用宏；检查缺键、重复键、未引用条目及正文引用与最终输出不一致。不要仅用简单正则宣称复杂 TeX 已被完整解析。

著录信息以用户提供的原文或可靠来源为准；仅用旧 bbl 可恢复已有内容，但不证明出版信息已核验。缺 DOI、作者、页码等标记待核，不推测补全。Zotero/Better BibTeX 自动生成文件优先回到来源更新；未授权不写数据库。按项目原构建顺序进行 LaTeX、BibTeX 或 biber 及后续编译，读取日志并核对 PDF 中引用，区分代码一致与来源核实。
