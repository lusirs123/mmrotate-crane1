## 核验与恢复

在项目根目录检查归档（默认不恢复、不运行模型）：

```bash
python archives/detection_configs_20261101/restore.py
```

确需重新运行历史训练器、八组消融或旧来源校验时，先恢复原路径：

```bash
python archives/detection_configs_20261101/restore.py --restore
```

恢复前检查所有SHA；目标路径已有不同内容时拒绝覆盖。恢复会使历史配置重新出现在原配置目录中，因此只在需要历史复现时执行。原训练器/审计中的路径与冻结来源合同未被批量改写；它们不会自动从本归档加载，未恢复前不保证其可运行。当前新入口不受影响。

这不是运行历史训练的授权。归档配置中的旧数据、权重与work_dir仍保留当时含义；原权重、缓存、预测和实验结果没有迁移或删除。归档仅作用于本机，服务器历史文件保持原状。

此前删除的旧DINO、source-val及可靠性组合配置3份没有重新放回；它们退出当前检测任务且可按[清理记录](../../docs/detection/配置清理记录_20261101.json)中的Git提交恢复。
